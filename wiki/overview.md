# 项目总览

## 这是什么

一个"写作方法 + 素材库 + 生产流水线"三位一体的网文项目。
目标不是完成一篇作品，而是建立一套**能持续产出、持续变强**的系统。

## 三层结构

```text
记忆层 memory/      ：我在哪、我要什么、我做过什么决定
知识层 wiki/        ：可复用的方法与素材（会越来越厚）
生产层 output/ + project/ ：选题、大纲、章节、复盘
```

## 闭环

```text
拆书 → 提炼 → 入库
   ↑              ↓
复盘 ← 数据 ← 写作 ← 选题
```

每转一圈，库更厚，下一本启动更快。

- 方法论 v0.1 完成，骨架已建。
- 阻塞项：题材方向、写作基础、每日投入未确认。
- 下一步：完成立项访谈 → 选题评估 → 黄金三章。
