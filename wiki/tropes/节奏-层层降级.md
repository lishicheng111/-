# 层层降级

- 类型：节奏 / 困境
- 核心机制：角色提出一个计划，现实立刻用**更糟的真相**击碎；角色再提计划，现实再用**更更糟**的击碎；层层下探直到谷底。每一层都是一个小钩子，读者想知道"还能更糟吗"。
- 压抑方式：角色的计划看起来合理，读者也觉得"这把稳了"，然后现实打脸。
- 释放方式：到谷底后要么摆烂（接受现实反而轻松），要么用一个意想不到的方式翻盘。
- 变体：
  - A 经营困境型：振兴医院 → 没病人 → 一半被收购 → 整个被收购（超脱力医院）
  - B 招兵买马型：想开宗立派 → 没人来 → 只有一个傻子 → 傻子是卧底
  - C 寻宝探险型：找宝藏 → 宝藏是空的 → 空箱子里有纸条 → 纸条写着"宝藏在隔壁" → 隔壁是厕所
- 适用题材：经营流、种田流、困境开篇、群像
- 禁忌：
  - 每层只是"更惨"而没有新信息 → 变成流水账
  - 降级太随意，没有因果 → 读者觉得作者在整主角
  - 一直降不释放 → 读者压抑过头弃书
