# 双线互潜

- 类型：结构 / 阵营对抗
- 核心机制：A 方派卧底渗透 B 方，**同时** B 方也派卧底渗透 A 方。双方都以为只有自己在暗处，都觉得"优势在我"。读者上帝视角看两边的卧底同时犯蠢，笑点和悬念并存。
- 压抑方式：两边的计划都看起来天衣无缝，读者知道两边都在演，但角色不知道。
- 释放方式：某个卧底的失误暴露全局，或者两边卧底在第三方场景碰面，发现彼此身份。
- 变体：
  - A 工作室互潜型：两个团队同时互派卧底，卧底各自犯蠢（马侯之交：阮阮上错车、鲸尾拿到的机密是 Tokyo Hot）
  - B 正邪互潜型：正道和魔道同时互派卧底，两个卧底在对方阵营成了朋友，还互相交换假情报
  - C 国家谍战型：两国同时派间谍，间谍在敌国混得比本国还好，不想回来了
- 适用题材：阵营对抗、谍战、商战、宗门大战
- 禁忌：
  - 只有一方在渗透 → 变成普通卧底线，没有互潜的笑点
  - 两边计划太对称 → 读者一眼看穿结局
  - 卧底失误太刻意 → 像作者强行降智
