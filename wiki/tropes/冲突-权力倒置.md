# 权力倒置

- 类型：冲突 / 关系反转
- 核心机制：下属/配角突然夺权，说出"现在我才是老板"，原主角/领导瞬间怂。不是真正的背叛，是**闹剧式的权力翻转**——夺权者也不正经，被夺者也不反抗，两人都在演。
- 压抑方式：先建立正常的上下级关系，让读者觉得"这是稳定的权力结构"。
- 释放方式：一个荒诞的契机（拿枪、改名、系统觉醒）打破结构，权力瞬间翻转。
- 变体：
  - A 下属篡位型：鲸尾拿枪指着雀巢，改名"逗比的鲸尾"
  - B 系统反叛型：主角的系统觉醒自我意识，把主角绑定成了下属
  - C 召唤物反噬型：主角召唤的魔物反客为主，让主角去打工养它
  - D 徒弟翻身型：徒弟学成后把师父赶出门，自己当掌门
- 适用题材：系统流、召唤流、师徒流、经营流
- 禁忌：
  - 夺权太认真 → 变成真背叛，破坏喜剧氛围
  - 原主角完全不反抗 → 失去主角光环
  - 翻转后没有后续 → 变成一次性段子
