# 幻想现实错位

- 类型：视角 / 内心戏
- 核心机制：角色沉浸在自己的**幻想/脑补**里（幻想要写得越燃越好），旁边的人用一句话把他**拉回现实**（拉回要越快越狠）。笑点来自幻想与现实的巨大落差。
- 压抑方式：用大段燃向描写写角色的内心戏，让读者也跟着燃起来。
- 释放方式：旁边人一句吐槽，瞬间破功。
- 变体：
  - A 战斗脑补型：主角脑补自己一挑十大杀四方，旁边小弟："大哥，对方就一个人，还是个老头"
  - B 恋爱脑补型：主角脑补对方暗恋自己，对方："你挡我路了"
  - C 装逼脑补型：主角脑补众人跪服，众人："你谁啊？"
- 适用题材：全题材通用，尤其适合装逼打脸前的铺垫
- 禁忌：
  - 幻想部分写得太长 → 读者不耐烦
  - 现实拉回不够狠 → 反差不够
  - 用太多 → 读者会觉得主角是个傻逼
