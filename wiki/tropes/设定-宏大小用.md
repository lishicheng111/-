# 宏大小用

- 类型：设定 / 金手指
- 核心机制：给角色一个**看起来很牛逼**的能力（时间回溯、精准定位、言出法随），但他只用它来做一件**极其渺小/荒诞**的事。能力越大，目标越小，反差越大越好笑。
- 压抑方式：先展示能力的牛逼之处，让读者以为"这下要干大事了"。
- 释放方式：角色用这个能力去做鸡毛蒜皮的事，读者预期落空产生笑料。
- 变体：
  - A 时间回溯型：能回溯时间，目的是阻止一个女生撞到自己（崩铁商单）
  - B 精准打击型：导弹级精准定位，用来崩飞粉丝裤衩
  - C 言出法随型：说什么成真，只用来跟菜市场大妈砍价
  - D 预知未来型：能预知未来，只用来猜明天食堂吃什么
- 适用题材：都市、轻小说、玄幻、仙侠（金手指设计）
- 禁忌：
  - 能力一直小用，偶尔也要大用一次 → 不然读者觉得浪费
  - 小用的目标不够具体 → 要具体到"砍价五毛钱"这种程度
  - 能力太强导致剧情没张力 → 要给能力加限制（冷却时间、使用次数）
