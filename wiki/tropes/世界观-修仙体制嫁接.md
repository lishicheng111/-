# 修仙+现代体制嫁接

- 类型：世界观 / 职业
- 来源：起点三江榜 2026-08~10（仙侠 13%，远超新人榜 6%，且全部是"新仙侠"）
- 核心机制：把修仙的"境界/法力/仙籍/功法"替换成现代职场的"职级/技能/编制/学历"，让读者对修仙世界立刻代入。**本质是用职场逻辑重构仙侠世界观**。

## 嫁接方式

| 修仙概念 | 现代对应 | 三江榜样本 |
| --- | --- | --- |
| 仙籍 | 职业资格证/编制 | 《不许没收我的仙籍！》 |
| 灵根/境界 | 职称/职级 | 公门修仙里的"炼气=科员、筑基=科长" |
| 功法 | 专业技能/学历 | 《公门修仙：从灵能署科员开始》 |
| 门派 | 机关单位/公司 | 灵能署 = 修仙体制内单位 |
| 渡劫 | 考核/晋升考试 | 《两界：从筑基失败开始成仙》 |
| 寿元 | 工龄/退休金 | 入赘百年 = 在公司待了一辈子 |

## 为什么有效

1. **读者秒懂规则**：不需要先花 3 章讲"什么是炼气、什么是筑基"，读者看"科员""科长""编制"立刻知道是什么地位。
2. **金手指落地自然**：主角的穿越/觉醒金手指 = 在体制内的"特殊能力"（情报系统、装备中药材），不突兀。
3. **情绪共鸣强**：升职、考编、考核——这些是读者现实中也在焦虑的事情，用修仙包装后，爽点更直接。

## 变体

- **A 纯体制嫁接**：灵能署 = 修仙版政府机关，主角考编制进去（公门修仙）
- **B 仙籍当职业**：修仙者有"仙籍"，被吊销就失业（不许没收我的仙籍）
- **C 两界互通**：主角在现代都市和修仙世界之间穿梭，用现代知识解决修仙问题
- **D 繁殖经营型**：多子多福 = 修仙界繁殖，后代越多势力越大（多子多福：开创仙朝）

## 禁忌

- **嫁接不彻底**：体制和修仙各玩各的，没有真正融合
- **规则太复杂**：修仙职场的职级体系比现实还复杂，读者记不住
- **体制太松**：主角随便就能升职，爽感透支
- **嫁接过界**：把修仙完全变成职场文，丢了仙侠的浪漫感
