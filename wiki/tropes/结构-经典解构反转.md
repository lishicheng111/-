# 经典解构反转

- 类型：结构 / 笑点
- 核心机制：拿读者**熟知的故事、套路、道德观**开刀，用反常识逻辑推翻预期。笑点来自"读者以为会发生A，实际发生了B"，而且B的逻辑自洽。
- 压抑方式：先顺着读者预期铺垫（让读者以为"果然是这个套路"），铺垫越足，反转越响。
- 释放方式：一句话/一个行为推翻前面所有铺垫，读者愣一下然后笑。
- 变体：
  - A 典故解构型：把孔融让梨、司马光砸缸这类典故的"正确答案"换成自私/现代逻辑（孔融："这个那个，不都是我的吗？"）
  - B 套路解构型：读者以为是"废柴逆袭"，实际是"原主在装废柴，我比他还能装"
  - C 职业解构型：读者以为侦探靠推理，实际靠瞎蒙但蒙对了；读者以为医生靠医术，实际所有病都诊断"发烧 下一个"
- 适用题材：全题材通用，尤其适合开篇钩子和日常章的笑点
- 禁忌：
  - 解构的东西读者不熟 → 反转没人 get
  - 反转逻辑不自洽 → 变成硬搞笑
  - 用太多 → 读者预判了你的预判
