# 起点机制与收益模型

> 状态：**部分核实（2026-11-09）**。§4.1 推荐机制已由起点编辑星河一手解读补全；收入模型仍为公开信息估算，签约、上架前必须以当期官方政策与合同为准。

## 1. 收入构成

| 来源 | 说明 | 稳定性 |
| --- | --- | --- |
| VIP 订阅分成 | 读者按章付费，作者按合同比例分成 | 核心，随均订增长 |
| 全勤奖 | 达到日更字数门槛的月度奖励 | 稳定但金额有限 |
| 月票奖 / 榜单奖 | 与月票排名挂钩 | 波动大 |
| 读者打赏 | 一次性收入 | 不可预测 |
| 渠道分成 | 站外渠道分发 | 后期才有 |
| 版权（影视/有声/出版） | 少数作品 | 不作为目标 |

## 2. 收入反推模型（估算）

```text
单章 3000 字，售价约 10–15 起点币（约 0.10–0.15 元，随会员等级浮动）
作者分成后约 0.05–0.075 元 / 订阅 / 章

日更 2 章 × 30 天 = 60 章 / 月
均订 3000 × 60 章 × 0.06 元 ≈ 10,800 元 / 月（税前，未计老章持续订阅）
```

**结论：月入 1 万的核心可控指标是均订 3000 左右；辅助指标是追读率与稳定更新。**

> 若日更 1 章，则需均订约 6000；若日更 3 章，均订约 2000 即可接近目标。
> 这解释了为什么"更新量"是新人最现实的杠杆。

## 3. 关键运营指标

| 指标 | 含义 | 用途 |
| --- | --- | --- |
| 追读率 | 从本章追到下一章的比例 | 判断开篇与钩子 |
| 收藏 | 加入书架人数 | 判断吸引力 |
| 推荐票 / 月票 | 核心粉丝活跃度 | 判断粉丝黏性 |
| 均订 | 章节平均订阅数 | 收入直接指标 |
| 追订比 | 追读与订阅的转化 | 判断付费意愿 |
| 完读率 | 单章读完比例 | 判断是否水 |

## 4. 新书期机制

### 4.1 2026 推荐改版：试水轮 + 培育轮（已核实）

> 来源：起点编辑星河《（十问十答）起点编辑星河解读「起点新书推荐改版」》，阅文作家专区，2026-11-09 检索。
> 状态：编辑一手解读，可信度高；具体执行以站内短信为准。

| 维度 | 旧机制 | 新机制 |
| --- | --- | --- |
| 推荐结构 | 1–4 轮 PK | 试水轮 + 培育轮 |
| 新人保障 | 追读不够可能光速掉队（大分类尤甚） | **签约后稳定更新，必有一周试水轮** |
| 复活机制 | 无 | 试水差、培育期数据不佳仍有**随时复活机会** |
| 流量分配 | 同轮竞争，慢热书易被吸光 | 一周公平给量，每两天一次测试机会，可换流量包 |
| 推荐周期 | 逐轮 PK | 培育轮流量固定（约等于以前二三四轮） |

**上试水的正确姿势**：

- 必须先"新书入库"（证明稳定更新 5 天），入库不是推荐位
- 理论上日万 6 天可排队，但**日更 4000–6000 且不断更**即可
- **上推后不需要爆更**——决定流量包的数据是多方面的，爆更作用不大
- 追读达标后可随时上三江强推，也可与编辑沟通卡点上架

**对本书项目的影响**：

1. 不需要为了"抢推荐"而前期爆更，**稳定日更 6000 是更优策略**（与项目 6000 字/日目标一致）
2. 试水轮表现差不必立刻切书，培育轮有复活机制
3. 选题准确度比"抢跑"更重要（分类要"准+精确"，不因轻小说/都市流量大就硬挤）

### 4.2 通用规律

- 断更会中断推荐与追读积累。
- 通常前 3 章决定读者去留，前 10 章决定是否养书。
- 签约标准不因改版提高；起点有编辑审核，会拦住 AI 与水平明显不足的书。
