# 起点机制与收益模型

> 状态：**TBD（待核实）**。以下为公开信息的粗略估算，用于建立决策模型，不作为承诺。
> 签约、上架前必须以当期官方政策与合同为准，核实后更新本页并标注日期。

## 1. 收入构成

| 来源 | 说明 | 稳定性 |
| --- | --- | --- |
| VIP 订阅分成 | 读者按章付费，作者按合同比例分成 | 核心，随均订增长 |
| 全勤奖 | 达到日更字数门槛的月度奖励 | 稳定但金额有限 |
| 月票奖 / 榜单奖 | 与月票排名挂钩 | 波动大 |
| 读者打赏 | 一次性收入 | 不可预测 |
| 渠道分成 | 站外渠道分发 | 后期才有 |
| 版权（影视/有声/出版） | 少数作品 | 不作为目标 |

## 2. 收入反推模型（估算）

```text
单章 3000 字，售价约 10–15 起点币（约 0.10–0.15 元，随会员等级浮动）
作者分成后约 0.05–0.075 元 / 订阅 / 章

日更 2 章 × 30 天 = 60 章 / 月
均订 3000 × 60 章 × 0.06 元 ≈ 10,800 元 / 月（税前，未计老章持续订阅）
```

**结论：月入 1 万的核心可控指标是均订 3000 左右；辅助指标是追读率与稳定更新。**

> 若日更 1 章，则需均订约 6000；若日更 3 章，均订约 2000 即可接近目标。
> 这解释了为什么"更新量"是新人最现实的杠杆。

## 3. 关键运营指标

| 指标 | 含义 | 用途 |
| --- | --- | --- |
| 追读率 | 从本章追到下一章的比例 | 判断开篇与钩子 |
| 收藏 | 加入书架人数 | 判断吸引力 |
| 推荐票 / 月票 | 核心粉丝活跃度 | 判断粉丝黏性 |
| 均订 | 章节平均订阅数 | 收入直接指标 |
| 追订比 | 追读与订阅的转化 | 判断付费意愿 |
| 完读率 | 单章读完比例 | 判断是否水 |

## 4. 新书期机制（待核实）

- 新书有推荐位周期，追读率决定能否进入下一轮。
- 断更会中断推荐与追读积累。
- 通常前 3 章决定读者去留，前 10 章决定是否养书。
