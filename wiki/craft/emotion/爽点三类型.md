# 爽点三类型

- 类型：爽点分类
- 来源：番茄官方《网络小说的爽点》
- 核心机制：番茄官方把爽点分为三种类型——**欲扬先抑、扮猪吃虎、极致碾压**。三者都通过塑造强烈反差调动情绪，反差越极致爽感越强。它们并非孤立，而是相辅相成，同一本书中会多次出现。

## 类型一：欲扬先抑

- **机制**：利用强烈剧情对比，创造极致反差感。
- **核心**：先把主角压到最低，再突然扬起来。
- **构思模式**：
  1. **升级感**：从弱到强，提升速度要区别于普通人形成对比。案例：《斗破苍穹》萧炎被退婚→遇药老→连升四级。
  2. **制造需求→满足需求→超预期满足**：给主角制造急迫且必要的需求，超预期达成时获得满足。
  3. **立场转变**：重生文常用，主角对反派态度前后反转。"曾经你对我爱答不理，现在我你高攀不起。"

## 类型二：扮猪吃虎

- **机制**：主角装弱/想平凡 → 配角上门挑衅 → 主角亮出真实身份实力 → 惊呆反派。
- **核心**：前期一定要重点写主角身份暴露前的境况，不能略过。
- **构思模式**：**多重身份、出人意料**。主角拥有声名在外但底细隐秘的多重身份，隐藏身份生活，随剧情暴露。
- **常见于**：女频马甲文、男频战神文。
- **案例**：穷女婿在丈母娘寿宴问"二十亿的坐哪"。

## 类型三：极致碾压（女频称"玛丽苏"）

- **机制**：全方位碾压反派，营造"我什么都比你强"的爽感。
- **四种套路**：
  1. 不管你有没有的，我都有
  2. 不管你喜欢谁，他/她都喜欢我
  3. 不管你多厉害，我一定比你更厉害
  4. 不管修炼有多难，丹符器阵我样样精通
- **构思模式**：
  1. **配角反衬主角**：配角千方百计得不到的，主角轻易拿到。铺垫好配角的不堪，与主角形成反差（全靠同行衬托）。
  2. **掌控一切的优越感（秀优越）**：利用攀比心理秀财富/地位/权力。划重点：不能让主角刻意炫耀，要制造反派挑衅主角，给主角秀优越的机会。
  3. **获得大众认可的认同感**：主角完成有成就感的事→得到大众赞许。男频"迪化文"就是利用配角脑补制造爽点。

## 三类型的关系

- 不是三选一，而是组合使用。
- 欲扬先抑是骨架（压→扬），扮猪吃虎和极致碾压是填充（怎么压、怎么扬的具体方式）。
- 例如：扮猪吃虎 = 欲扬先抑 + 身份反差；极致碾压 = 欲扬先抑 + 全方位对比。

## 禁忌

- **欲扬先抑**：抑不能太久（小循环 ≤ 5 章），扬必须匹配抑的量级。
- **扮猪吃虎**：暴露前的境况必须写足，否则反差不够。
- **极致碾压**：不能让主角刻意炫耀，要让反派主动挑衅。
