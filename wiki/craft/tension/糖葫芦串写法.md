# 糖葫芦串写法（铺垫-高潮-收获）

- 类型：节奏 / 施工图
- 核心机制：把全书拆成一串"糖葫芦"——**每个爽点剧情 = 铺垫 → 高潮 → 收获**，一个糖葫芦吃完，紧接着开下一个。三个环节都必要，**铺垫最关键**。
- 来源：阅文编辑开放日（起点三组责编武行），与起点编辑星河同属起点编辑体系，可作为"代入感/期待感"落地的施工图。

## 为什么叫糖葫芦串

因为每个剧情单元结构相同、首尾相接、串成一条主线。读者每吃一颗（一个爽点），就被下一颗（下一个铺垫）勾着往前走。

```text
糖葫芦 1：铺垫 → 高潮 → 收获
                    ↓（收获同时开启下一个铺垫）
糖葫芦 2：铺垫 → 高潮 → 收获
                    ↓
糖葫芦 3：……
```

## 三段拆解

### ① 铺垫（最关键）

目标：把读者的情绪压到最低点，让他们**迫切期待主角出手**。

写法：
- 让反派/环境先把主角逼到墙角
- 让配角表现出"完了、要死了、没救了"
- 局势越紧张，后面高潮越爽

《重生之都市修仙》示例：KTV 里同伴被看不起 → 同伴惹事 → 主角出面但没出手 → 对面大佬发怒 → 眼看要死 → 全是铺垫。

**新人的通病是铺垫不足**：一上来主角就赢了，读者还没开始期待，爽点就没了。

### ② 高潮

目标：主角出手，一次性释放所有被压住的情绪。

写法：
- 主角出手要"超出读者预期"（不是刚好赢，是碾压式赢）
- 可以叠加"背后的大人物出手震慑"这种二段爽

### ③ 收获

目标：给读者一个明确的"赢了什么"，同时**开启下一个糖葫芦**。

收获必须具体：
- 物质收获（钱、宝物、地位）
- 社会收获（大佬认可、众人吹捧）
- 情感收获（女主另眼相看）
- **并埋下下一个矛盾**（新的敌人出现、新的目标出现）

## 配套技巧：动作-反应

这是糖葫芦串的"血肉"，决定爽点够不够爽：

```text
主角出手前：写配角反应（看不起 / 担心 / 嘲讽）
主角出手：写动作
主角出手后：写配角反应（震惊 / 沉默 / 称赞）
```

**大佬的反应最重要，爽点就在这。**

文娱类最典型的例子：主角上台唱歌——
1. 上台前：众人不看好、嘲笑
2. 唱的时候：众人逐渐沉浸
3. 唱完之后：全场震惊，**尤其是行业大佬的反应**

同一个动作，配角的反应写三遍（前/中/后），爽感翻三倍。

## 六步开书法（配套流程）

起点编辑体系给新人的开书路径：

1. **题材和方向**：先做市场调研，对照三江强推看当下什么题材在榜
2. **文笔和写法**：糖葫芦串 + 动作-反应
3. **主角人设、主线**：主角必须有**身份/职业**；主线是升级线，要写进简介
4. **一万字开头 + 五六万字细纲**：对应前几串糖葫芦
5. **投稿**：题材、身份、主线、开局剧情齐了，就能投
6. **发布**：书名、简介后续再定

### 主角必须有身份

> 编辑原话大意：没有身份，就会写成"穿越→路边拿出一首《曾经的你》→路人喊牛逼"这种没有细节和真实感的烂俗剧情。

身份的作用：
- 围绕身份写剧情 → 自然引出矛盾
- 有身份才有具体的事发生
- 例：文娱=演员/歌手；玄幻=捕快；历史=小侯爷
