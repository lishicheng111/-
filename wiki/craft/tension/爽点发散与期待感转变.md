# 爽点发散与期待感转变

- 类型：爽点设计 / 防同质化 / 长篇节奏
- 核心机制：同质化不可避免，但同一爽点重复会腻；需要在适当的时机（主角解决完生存危机后）铺垫期待感的转变：从"自己变强"→"守护某个东西"
- 结构参考（百万字循环）：
  - 前三分之一：主角个人生存危机 → 爽点集中在"变强"
  - 中间三分之一：主角需求转变 → 爽点发散到"社会 / 关系 / 守护"
  - 后三分之一：社会危机 → 换地图或升级迭代
- 关键规则：转变**必须有剧情铺垫**，不能突然让主角开始"大谈社会责任"——读者会骂你跑偏；如果没把握铺垫，不如只写单一爽点，保持纯粹
- 禁忌：为了避免同质化而强改爽点，导致读者流失（因为前期已经筛选过读者，没铺垫的变更是对留下来读者的背叛）
- 适用：百万字以上长篇，需要迭代爽点的作品
