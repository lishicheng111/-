# 代入感与期待感

- 类型：节奏 / 总纲
- 核心机制：**网文只有两个东西——代入感和期待感**。代入感解决"能不能看进去"，期待感解决"想不想看下去"。所有技巧最终都服务于这两件事。
- 来源：起点编辑星河 B 站切片原话："网文就两个东西，代入感和期待感。没代入感，读者看不进去你开头；没期待感，读者不想看你后面内容。这两点非常关键。"

## 为什么这是总纲

其他所有技巧都能归到这两项：

| 技巧 | 服务于 |
| --- | --- |
| 开篇 500 字有主角 | 代入感 |
| 主角主动推进剧情 | 代入感 |
| 降低阅读障碍 | 代入感 |
| 人物立得住 | 代入感 |
| 章末钩子 | 期待感 |
| 目标/Boss 关系 | 期待感 |
| 金手指限制 | 期待感 |
| 大小期待衔接 | 期待感 |

**自检方法**：写完一章问两句——
1. 读者这一章有没有"我就是主角"的感觉？（代入感）
2. 读者想不想知道下一章发生什么？（期待感）
两个都答"否"，这章就是废章。

## 代入感：让读者觉得"我就是他"

### 四个来源

| 来源 | 做法 | 反例 |
| --- | --- | --- |
| 欲望可共享 | 主角想要的，读者也想要（钱、尊严、被认可、复仇） | 主角想要的东西读者无感（比如收集邮票） |
| 处境可想象 | 主角的困境读者能代入（被看不起、被裁员、被退婚） | 主角处境离普通人太远且无解释 |
| 反应可信 | 主角的反应符合普通人直觉（先怕，再硬） | 主角全程无情绪、像工具人 |
| 信息对等 | 读者知道的≈主角知道的，不藏关键信息 | 主角知道但读者不知道，读者被排除在外 |

### 三个破坏代入感的行为

1. **主角旁观**：整章被叫去→被告知→震惊，主角不做事
2. **主角降智**：为了推进剧情让主角做蠢事
3. **主角无目标**：读者不知道他要干什么，代入不进去

### 检查清单

- [ ] 这一章主角有没有做至少一个**主动选择**？
- [ ] 主角的欲望，普通读者能不能共情？
- [ ] 主角的反应，换成读者自己会不会也这样？
- [ ] 有没有"读者不知道但主角知道"的关键信息藏着？

## 期待感：让读者想翻下一章

### 三层期待

| 层级 | 时间跨度 | 例子 |
| --- | --- | --- |
| 微期待 | 本章内 | 他能不能打赢这一架 |
| 中期待 | 3–10 章 | 他能不能进这个宗门 |
| 大期待 | 全书 | 他能不能站到最高处 |

三层必须同时存在，缺一层读者就会掉。

### 四个来源

1. **目标未达成**：明确告诉读者"他要干什么"，然后拖着不给他
2. **危机未解除**：倒计时、追杀、毒发
3. **信息差未揭晓**：读者知道有秘密，但不知道是什么
4. **关系未确定**：这两个人到底会不会在一起

### 检查清单

- [ ] 这一章结尾，读者有没有一个明确的"我想知道"？
- [ ] 微/中/大三层期待，现在各是什么？
- [ ] 钩子是"具体事件"还是"欲知后事如何"？（必须是前者）

## 两者的关系

```text
代入感 = 入口（决定读者进不进来）
期待感 = 留存（决定读者留不留下）
```

- 只有代入感没有期待感：读者觉得"这主角挺真实"，但不想看下去
- 只有期待感没有代入感：读者好奇剧情，但不关心主角死活
- **先代入，再期待**：开篇优先解决代入感（立人物），中后期靠期待感拉长线
