# 装二手逼角色

- 类型：人物设计 / 期待感
- 核心机制：写一个"看起来厉害但还没真正出手"的角色，读者看到他出场就会期待他哪天能装一次逼——相当于把角色变成了一个"定时兑现的钩子"
- 操作步骤：
  1. 先暗示角色实力 / 背景（比如"据说十年前一个人屠了一整个宗门"但全书还没见过他真出手）
  2. 出场时态度先压（别人看不起他 / 他低调），期待值拉低
  3. 等到某个关键节点让他出手一次（只需要一次就能让读者记住）
  4. 装完逼后不要让他变成主角 / 不要让他取代主角行动
- 禁忌：装二手逼的角色抢主角戏；装完逼后戏份多到变成主角 → 主角被边缘化
- 适用：玄幻、都市、升级流的长线钩子；尤其适合作为新地图"先去后回"里的那个引路人角色
