# 原型借力（熟悉的陌生人）

- 类型：人物塑造 / 读者认知成本
- 核心机制：直接借用**读者已经自带认知的网络原型**（人机、嘉豪、显眼包、中登、社恐、卷王），角色一登场，读者自动加载一整套"约定俗成的默认设定"，作者省掉大段铺垫；再用**反差**打掉其中一条默认设定，制造记忆点和笑点。
- 为什么有效：
  - 读者认知成本最低：不用记新名字新背景，报出原型名就懂了
  - 期待感天然存在：读者知道这类人"应该"怎么表现，于是会等"他什么时候破功"
  - 反差有杠杆：默认预期越强，掀翻时的落差越大
- 操作公式：

```text
原型名（读者默认包） + 保留 80% 默认 + 掀翻 1 条核心默认 = 有记忆点的新角色
```

保留太多 → 刻板印象；掀翻太多 → 读者认不出原型，借力失效。

- 三条用法：
  1. **主角借力**：用一个强原型当外壳，反差当内核（人机校花其实是游戏大神）
  2. **配角借力**：原型直接当功能标签，读者一眼记住（嘉豪型死党负责装逼翻车）
  3. **反派借力**：用读者讨厌的原型，快速建立反感（爹味说教型反派）
- 选择原型的标准：
  - 必须是**当下还在流通的梗**，过气梗读者 load 不出来
  - 必须能**一句话说清**，说不清就说明认知成本不低
  - 必须有**可翻的反差点**，没反差的原型只能当背景板
- 禁忌：
  - 用贬义原型当主角却不给反差 → 读者讨厌主角
  - 原型堆太多 → 主角变成标签拼盘
  - 梗太垂直（小众圈层梗）→ 起点大众读者 get 不到
  - 过气梗硬用 → 读者觉得土
