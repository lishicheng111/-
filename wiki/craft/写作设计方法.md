# 写作设计方法 v0.1

> 适用：起点中文网长篇连载（男频为主，女频结构可复用）
> 状态：v0.1 基线。随拆书与实战迭代，改动写入 `wiki/log.md`。
> 来源：通用叙事原则 + 起点连载商业逻辑 + 待验证假设（标 TBD 的部分需实测）

---

## 0. 底层公式

```text
追读率 × 更新稳定性 × 爽点密度 × 累计字数 = 订阅量 ≈ 收入
```

- **追读率**：有多少读者从这一章追到下一章。它决定推荐，推荐决定曝光。
- **更新稳定性**：断更一次，追读掉一截，推荐位可能直接断。
- **爽点密度**：读者每隔几章能获得一次明确情绪兑现。
- **累计字数**：订阅有复利，老章也在持续产生收入。

推论：**新书期不追求"写得深"，追求"追得住"。** 深度是均订稳定之后的事。

## 1. 定位层：动笔前先算题

### 1.1 赛道四问

1. 读者是谁：年龄、性别、阅读场景（通勤/睡前）、核心情绪需求（爽/燃/甜/怕/烧脑）。
2. 供给多不多：同题材在榜作品数量与更新量。
3. 平台在推什么：新书榜、分类榜当前风向。
4. 我有什么别人没有的：职业经验、知识储备、独特视角、梗的库存。

四问里答不出第 4 条，就不要开书——那意味着你只能拼更新量。

### 1.2 一句话卖点公式

```text
[主角身份/处境] + [核心金手指或设定] + [要解决的终极问题] + [差异化钩子]
```

- 反例："一个少年在修仙世界变强。"（没有信息量，谁都能写）
- 正例："殡仪馆化妆师能看见死者最后一句话，他靠这个破案，却发现父亲当年的死另有隐情。"

检验：把这句话给一个不看网文的人，他能不能在 10 秒内问出"然后呢？"

### 1.3 竞品拆解（至少 3 本）

记录：前 10 章发生了什么、金手指是什么、几章一个爽点、日更多少、评论区的high点与骂点。
判断：**我能不能在这个赛道做到前 30%？** 做不到就换更窄的赛道。

---

## 2. 引擎层：故事核心循环

引擎 = 主角每个阶段重复执行的"欲望 → 阻碍 → 兑现 → 升级"。

| 引擎 | 循环 | 适合 |
| --- | --- | --- |
| 升级流 | 变强 → 更强的敌人 → 再变强 | 玄幻、仙侠、游戏 |
| 资源流 | 获取 → 扩张 → 守护 → 被觊觎 | 种田、经营、都市 |
| 解谜流 | 疑问 → 线索 → 真相 → 更大疑问 | 悬疑、无限流 |
| 关系流 | 靠近 → 误会 → 拉扯 → 确认 | 言情、都市情感 |

**检验标准：用一句话说出"读者每 3 章能看到什么"。说不出来，引擎不成立。**

---

## 3. 人物层

### 3.1 主角三要素

- **欲望可代入**：他想要的东西，读者也想得到。
- **能力可成长**：有清晰阶梯，读者能感知进步。
- **底线可冲突**：他有 3–5 条绝不违背的铁律（Soul Field），剧情靠撞这些铁律产生。

### 3.2 Soul Field（灵魂场）

写死 3–5 条行为铁律，全书不许破例：
"朋友有难必救，不算计" / "不主动伤及无辜" / "承诺必兑" / "被背叛会痛，但先给对方解释机会"。

剧情需要他破例时：**改剧情，不改人设。**

### 3.3 配角功能表

每个有名有姓的配角，必须至少占一项功能：提供信息 / 制造阻碍 / 情感锚点 / 衬托主角 / 承担笑点。
一项都不占 → 合并或删除。

### 3.4 反派

反派与主角共用同一套力量规则和世界规则。**不能靠"反派突然变蠢"制造胜利**——那是读者弃书的高发点。

---

## 4. 结构层

### 4.1 三级结构

```text
卷（20–40 万字）→ 弧（30–50 章）→ 章（2000–3500 字）
```

### 4.2 起点节奏表

| 位置 | 必须发生 |
| --- | --- |
| 第 1 章 | 主角具体困境 + 金手指/异常出现 + 一个指向明天的钩子 |
| 第 2 章 | 首次小爽点 + 世界观自然露出（不讲解） |
| 第 3 章 | 主线目标确立 + 强追读钩子 |
| 第 10 章 | 第一个完整的"压抑→反转→释放"闭环 |
| 第 30–50 章 | 第一卷高潮 + 地图/境界升级 |
| 每 3–5 章 | 一个小爽点 |
| 每章末 | 一个具体钩子 |

### 4.3 伏笔表

每条记录：埋设章 / 内容 / 计划回收章 / 状态（未回收/已回收/已废弃）。
埋了 30 章不还，读者会当成作者忘了；永远不还，是失信。

### 4.4 张力曲线

不可能每章都高潮。**张弛交替**：高潮弧之后必须给 1–2 章缓冲（日常/情感/世界观），再起下一波。
缓冲章也要有钩子，只是强度低。

---

## 5. 单章施工图

### 5.1 五段式

1. **承接**：接住上一章钩子（1–2 段，别复述）。
2. **目标**：本章主角要做什么，一句话说清。
3. **阻碍**：具体的人、规则或时间限制。
4. **转折/兑现**：爽点或代价，必须具体。
5. **钩子**：指向下一章将发生的事。

### 5.2 字数配比（参考）

```text
承接 10% | 推进 50% | 爽点/转折 30% | 钩子 10%
```

爽点占比长期低于 20% → 读者会觉得"水"。

### 5.3 三种章型轮换

- **推进章**：给信息、立目标、换地图。
- **冲突章**：打脸、战斗、对峙、摊牌。
- **缓冲章**：日常、情感、世界观、笑点。

连续 3 章同一章型 → 节奏疲劳，必须换。

---

## 6. 爽点与钩子

### 6.1 爽点七型

打脸 / 升级 / 获得 / 守护 / 智斗 / 身份揭露 / 情感确认。

### 6.2 爽点公式

```text
压抑（读者憋屈）→ 反转（信息差兑现）→ 释放（具体动作）→ 余韵（旁人反应）
```

- 压抑不够 → 爽不起来。
- 释放不具体（只写"他赢了"）→ 假爽。
- 没有余韵（旁人震惊/态度变化）→ 爽点没有回声。

### 6.3 钩子四型

| 类型 | 例子 |
| --- | --- |
| 信息钩 | 他翻开那本名册，第一页写着自己的名字 |
| 情绪钩 | 她笑着说"没关系"，然后把手抽了回去 |
| 危机钩 | 倒计时还剩 3 分钟，门外的脚步停了 |
| 承诺钩 | "三天后，我会回来取你的命" |

### 6.4 强度阶梯

章末小钩（每章）→ 卷末中钩（每 30–50 章）→ 全书大钩（1–3 个）。

### 6.5 兑现纪律

**每个钩子都要登记兑现章。** 埋了不还，读者会记账。

---

## 7. 文笔层：网文语感

- **短句为主，长短交替**。手机阅读，一段 1–3 行为宜。
- **一段一个信息点**，不要一段塞三个转折。
- **动作节拍代替"他说"**：`他把杯子往桌上一顿。"不去。"`
- **画面感 = 具体名词 + 感官**，少用形容词。
- **对话推进剧情**，不要用对话解释设定。
- **避免 AI 味**：空泛副词、排比堆叠、"仿佛/似乎"连用、每段等长、模板化情绪、等距时间线。

> 详版见 story-craft 技能 §7（表达原则）与 §8（13 种 AI 味模式）。

---

## 8. 世界观层

- **规则即冲突**：设定存在的意义是制造麻烦，不是展示想象力。
- **力量体系**：阶梯清晰 + 每一级有明确代价 + 有天花板。
- **地图随主角成长解锁**，不要一开篇铺满世界。
- **社会规则承载主要冲突**：阶级、法律、禁忌、资源分配。
- 自查：把这个世界观换到另一个故事里还能用 → 说明耦合太弱，是通用背景板。

## 9. 数据层诊断

| 指标 | 症状 | 处方 |
| --- | --- | --- |
| 追读率低 | 看完不追下一章 | 章末钩子弱 / 开篇慢 / 主角被动 |
| 收藏涨、订阅低 | 养书多、付费少 | 上架前期待感没建立，爽点兑现太晚 |
| 均订停滞 | 中后期乏力 | 引擎重复、敌人强度不够、人物扁平 |
| 完读率低 | 章节太长或太水 | 砍日常，把冲突提前 |
| 月票少 | 核心粉丝少 | 缺"名场面"和情感锚点 |
| 评论骂点多 | 期待错位 | 检查标签、简介与正文是否一致 |

**数据只用于定位问题，不用于自我否定。** 每次只改一个变量，观察 3–5 天。

## 10. 每章自检清单

1. 开头接住上一章的钩子了吗？
2. 本章主角主动做了什么？
3. 有没有一个新信息或新问题？
4. 爽点/情绪兑现了吗？具体吗？
5. 章末钩子是否指向具体事件？
6. 有没有连续 4 句纯对话、只靠"他说"？
7. 有没有空泛副词和 AI 套话？
8. 段落长度有变化吗？
9. 有没有违反已立的世界观规则？
10. 删掉哪一段都不影响剧情？（那就删）

---

## 11. 长线状态管理

长篇崩盘，多数不是写不动，是记不住。每本书必须维护六件套：

| 文件 | 作用 |
| --- | --- |
| `arcs/剧情线状态机.md` | 每条线的五阶段：酝酿→触发→升级→高潮→收束 |
| `state/伏笔表.md` | 伏笔埋设与回收 |
| `state/已用桥段.md` | 用过桥段与变体，防止重复 |
| `state/已确立事实.md` | 已确立的规则与出处章节 |
| `state/人物当前状态.md` | 身体/情绪/已知信息/关系/携带物 |
| `state/下一章钩子.md` | 下一章必须兑现的钩子 |

**每写完一章就更新，不许靠记忆。**

---

## 12. 常见死法

1. 前三章都在铺世界观，主角还没干事。
2. 主角被动，剧情全靠别人推着走。
3. 金手指太强，没有像样的阻碍。
4. 爽点一直延迟兑现，读者先跑了。
5. 断更。
6. 中期换地图，力量体系和人物关系一起崩。
7. 配角抢戏，主角变成摄像头。
8. 追热点，但自己完全不懂那个领域。
9. 只写自己爽的，不写读者想看的。
10. 数据已经很差，还硬写 50 万字不回头。
