# 历史文同人化写法

- 日期：2026-11-09
- 版本：v0.1
- 状态：草稿
- 来源：用户口述方法论（2026-11-09）+ 起点三江同人作品观察（[起点三江榜-2026-同人作品](../analyses/起点三江榜-2026-同人作品.md)）
- 适用：三国、春秋战国、两晋、唐、宋、明等所有历史题材

## 核心公式

> **历史人物 = 公有领域的免费 IP**
> **正史 = 官方设定集**
> **野史 = 同人二创**
> **二创梗 = 皮肤**
> **改命 = 反差**

一句话：**把历史当同人文写，读者零成本认领，作者零版权风险。**

## 一、为什么历史文天然是同人文

| 同人文要素 | 历史文的对应 |
| --- | --- |
| 原作 | 正史（《三国志》《史记》） |
| 原作粉 | 历史爱好者、考据党 |
| 人设包 | 一提诸葛亮＝智慧，一提曹操＝奸雄 |
| 官方结局 | 史书写的死法 |
| 二创空间 | 野史、笔记、民间传说 |
| 圈层暗号 | 三国杀台词、影视名场面、网络梗 |

**关键**：读者对历史人物有**预期结局**。这个预期就是最大的钩子——你说"我要改他的命"，读者立刻想知道"怎么改"。

## 二、三层素材库

写历史文，素材必须分三层，用法和风险完全不同。

| 层 | 来源 | 用法 | 风险 |
| --- | --- | --- | --- |
| **正史层** | 《三国志》《后汉书》《资治通鉴》 | 骨架。时间、地点、官职、人际关系不能错 | 改多了被考据党骂 |
| **野史层** | 《世说新语》、笔记小说、地方志、民间传说 | 血肉。私德、轶事、传闻，可以大胆用 | 必须在作话标注"此为野史" |
| **二创层** | 三国杀、影视剧、游戏、网络梗 | 皮肤。用来拉近距离、制造记忆点 | **绝不能当史实用** |

### 操作原则

1. **骨架用正史，血肉用野史，皮肤用二创**
2. 野史要在**作者的话**里标注，这是对考据党的尊重，也是免责
3. 二创梗只能用来"让人物更鲜活"，不能用来"解释历史事件"

## 三、改命公式

> **原结局 + 反差方向 = 新故事**

改命不是"让他活下来"这么简单，而是**给他一个和原结局形成反差的命运**。

### 反差方向对照表

| 原结局 | 反差方向 | 效果 |
| --- | --- | --- |
| 被诛 | 成功，但发现成功是骗局 | 悲壮 |
| 战死 | 没死，但活成了自己最恨的人 | 残酷 |
| 被冤杀 | 早就知道，故意求死 | 震撼 |
| 病死 | 装病，等一个机会 | 智斗 |
| 投降 | 假降，反手一击 | 爽 |
| 功成身退 | 退不了，被自己人拦下 | 无奈 |

### 案例（可直接借鉴）

| 人物 | 史书结局 | 反差改法 | 话题性 |
| --- | --- | --- | --- |
| **魏讽** | 谋反被诛 | 谋反成功，却发现自己是刀 | ★★★ 本书 |
| 吕布 | 白门楼被缢 | 没死，成了某人的暗棋 | ★★★ |
| 杨修 | 鸡肋事件被杀 | 他早就看穿，故意求死 | ★★★ |
| 马谡 | 失街亭被斩 | 守住了，但被诸葛亮卖了 | ★★ |
| 韩信 | 长乐宫被杀 | 提前知道，将计就计 | ★★★ |
| 岳飞 | 风波亭 | 十二道金牌是假的 | ★★（敏感） |

## 四、话题性命运的设计

"话题性"就是**让读者在评论区吵起来**。三种最有效：

### 1. 该不该（道德争议）

- "魏讽到底该不该反？"
- "他为了兴汉害死王粲二子，值吗？"
- 设计方法：让主角做一个**两难选择**，两边都有道理

### 2. 如果（假设历史）

- "如果魏讽成功了，三国会怎样？"
- 设计方法：在关键节点埋一个"岔路"，让读者自己推演

### 3. 谁对谁错（阵营争议）

- "钟繇该不该举荐魏讽？"
- "陈祎告密是对是错？"
- 设计方法：**不给反派贴标签**，让每个角色都有自己的道理

> 争议越持久，书越容易被讨论。但争议要控制在"历史假设"层面，不碰现实。

## 五、黑历史与野史的使用边界

### 可以放心用

- 私德轶事（好色、贪财、怕老婆）
- 民间传闻（出生异象、梦中预言）
- 政敌抹黑（"奸雄""倾邪"这类判词）

### 需要谨慎

- 涉及民族关系的（五胡乱华、宋金）
- 涉及宗教的
- 涉及现实政治映射的

### 绝对禁用

- **编造史实冒充正史**（可以说"野史载"，不能说"史书记载"）
- 恶意抹黑有明确史料支撑的人物
- 把二创梗写成历史事实

## 六、改命必须付代价

这是最容易写崩的地方。

**改命 = 逆天，逆天 = 要还债。**

| 代价类型 | 例子 |
| --- | --- |
| 失去某人 | 救了魏讽，王粲二子还是死了 |
| 变成另一个人 | 为了活命，做了自己最恨的事 |
| 历史反噬 | 改了这件事，另一件事变得更糟 |
| 记忆代价 | 活下来了，但忘了为什么而活 |

> 没有代价的改命＝爽文流水账。有代价的改命＝读者会记住。

## 八、自检清单

写历史文前，逐条问自己：

- [ ] 我的正史骨架有没有硬伤？（时间、地点、官职、关系）
- [ ] 我用的野史有没有在作话标注？
- [ ] 主角的改命有没有形成"反差"，还是只是"活下来"？
- [ ] 改命有没有付代价？
- [ ] 有没有至少一个"该不该"的两难选择？
- [ ] 反派有没有自己的道理？
- [ ] 二创梗有没有被误当成史实？

## 九、轻历史变体：事件—吐槽—降维

- 样本：《从新三归来的马谡》（2026-10 三江，历史类）
- 特征：不追求考据，把历史当"事件"，用现代人视角吐槽，再用现代概念解释

### 三段式

| 段 | 做什么 | 示例 |
| --- | --- | --- |
| **事件** | 还原历史场景（史书原文 / 影视名场面） | 马谡失街亭 |
| **吐槽** | 主角用现代人的第一反应 | "这不就是典型的职场背锅吗" |
| **降维** | 用现代概念解释古代逻辑 | "所谓军令状，本质是责任转移协议" |

### 为什么有效

> **吐槽是把"解释"伪装成"反应"。**

读者以为在看主角发牢骚，其实在被科普。这是[降低阅读障碍](../tension/降低阅读障碍.md)的最高级形态——不觉得被教，只觉得被理解。

### 和已有方法的六处呼应

| 已有零件 | 呼应点 | 差异 |
| --- | --- | --- |
| [乐子人围观](../../tropes/视角-乐子人围观.md) | 主角不站 C 位，靠评论产生存在感 | 乐子人纯旁观，这里参与后再吐槽 |
| [伪获得感](../reader-gain/伪获得感.md) | 用现代概念解释古代事 | 伪获得感偏"学到知识"，这里偏"说出我心声" |
| [鹏鹏式知识点模板](../reader-gain/鹏鹏式知识点植入模板.md) | 场景 → 点破理论名 | 结构同构，一个用理论名，一个用吐槽 |
| 剧透流（见 [三国题材盘点](../../analyses/起点三国题材-分类与系统盘点.md)） | 知道结局才有吐槽资格 | 吐槽常建立在"我知道后面要翻车" |
| [降低阅读障碍](../tension/降低阅读障碍.md) | 现代语言、现代类比 | 那是手段，吐槽是载体 |
| [糖葫芦串写法](../tension/糖葫芦串写法.md) | 每个事件一串铺垫—高潮—收获 | 吐槽是微缩版糖葫芦 |

### 两种反差的区别（关键）

| 类型 | 变了什么 | 成本 | 代表 |
| --- | --- | --- | --- |
| **改命反差** | 命运变了（马谡没死） | 高，要重写历史 | 传统历史穿越 |
| **认知反差** | 看法变了（原来他不是蠢） | 低，不改历史也行 | 轻历史吐槽流 |

轻历史主要卖第二种。**成本低、见效快、不惹考据党。**

### 对《三国：杀贼荣光》的三条适配

1. **吐槽给内心，行动给外部**——不能整章只吐槽，主角必须推进剧情
2. **让演说本身成为吐槽**——魏讽当众用现代逻辑解构权威，这在古代就叫"惑众才"
3. **吐槽必须付代价**——说错一句就是死，这是历史文紧张感的来源

> 第 2 条最重要：**"惑众才"就是古代版的弹幕。** 他把读者想说的话，当着满朝文武的面说了出来。

### 风险

吐槽过量会消解严肃。解法：**严肃事件零吐槽，荒诞事件才吐槽。** 王粲二子被诛不能吐槽，曹操封王的大典可以。
