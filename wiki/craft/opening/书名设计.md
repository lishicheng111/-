# 书名设计

- 类型：开篇 / 编辑视角
- 核心机制：书名是读者和算法看到的第一信息。好的书名让读者一眼懂、算法一秒归类；差的书名直接劝退读者、误导算法。
- 本质：书名 = 20% 文学性 + 80% 功能性（让算法打对标签、让读者秒懂卖点）

## 书名的三个功能

1. **让算法打对标签**：起点推荐算法根据书名/简介/标签分配流量包，书名错了=流量包错了
2. **让读者秒懂卖点**：读者扫榜单时，书名要在 1 秒内传递"这本书讲什么、有什么爽点"
3. **避免劝退**：书名不能让读者觉得"这书我看不懂/不感兴趣"

## 五条书名铁律

### 1. 非同人书名不带同人元素

> 来自起点编辑星河："不是同人文的话，书名不要带同人元素。否则上试水推难度翻倍！"

- 原创文书名带"斗罗""火影""海贼"等同人词，算法会误判为同人，导致试水推流量包变小
- 如果确实想写同人，就老老实实挂同人分类，不要蹭原创流量

### 2. 书名要带"标签词"

让算法和读者一眼懂是什么书：

| 题材 | 标签词示例 |
| --- | --- |
| 修仙 | 修仙、炼气、金丹、元婴、宗门 |
| 都市 | 都市、重生、校花、神医、战神 |
| 历史 | 三国、大唐、大明、穿越、争霸 |
| 科幻 | 赛博、星际、机甲、末世 |
| 同人 | 直接写 IP 名（斗罗、火影） |

### 3. 书名要带"爽点暗示"

光有标签不够，还要让读者知道"爽在哪"：

| 书名 | 标签 | 爽点暗示 |
| --- | --- | --- |
| 《虐菜就会变强？我连夜加盟中超》 | 体育 | 虐菜=爽 |
| 《斗罗绝世：我，最后的天灾》 | 同人 | 天灾=强 |
| 《全人类都登录了，只有我能退出》 | 科幻 | 只有我能=特权 |
| 《华娱：乐子人在线吃瓜！》 | 都市 | 乐子人=有趣 |

### 4. 书名控制在 15 字以内

- 太长的书名在榜单上显示不全，关键信息被截断
- 15 字以内能完整显示，且读者 1 秒能扫完

### 5. 书名不要"文青病"

- 差的书名：《星河彼岸的约定》《岁月如歌》《风居住的街道》——读者完全不知道讲什么
- 好的书名：《重生后我成了校花的同桌》《修仙：从签到开始》——一眼懂

## 书名公式

```text
[题材标签] + [爽点/设定暗示] + [反差/悬念]
```

- 例：《都市：重生后我成了校花的同桌》
  - 题材标签：都市
  - 爽点暗示：重生、校花
  - 反差：成了同桌（期待被校花看上）

- 例：《修仙：从签到开始无敌》
  - 题材标签：修仙
  - 爽点暗示：签到、无敌
  - 反差：无（签到流本身就是反差）

## 书名禁忌

| 禁忌 | 为什么 |
| --- | --- |
| 带同人元素但不写同人 | 算法误判，试水推难度翻倍 |
| 太文艺/太抽象 | 读者看不懂，不点 |
| 太长（>15字） | 榜单显示不全 |
| 全是虚词（岁月/星河/风） | 没有信息量 |
| 用生僻字 | 读者打不出来，搜不到 |
| 和已有爆款书名太像 | 被算法判定为抄袭，限流 |
