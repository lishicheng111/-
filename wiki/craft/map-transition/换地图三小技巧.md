# 换地图三小技巧

- 类型：结构 / 换地图 / 追读
- 核心机制：新地图不能是一张白纸，要在"熟悉感"中推进"新鲜感"，减少读者陌生感
- 三个可复用机制：

**人来人往**：切小地图时，不要让主角一个人去。让身边熟悉的配角一起去，方便穿插旧关系剧情，减少新地图冷启动。

**先去后回**：在超级大高潮前（比如主角高考 / 突破），先让主角以"短暂接触"的方式去一次新地图（比如去大学参观）。让新地图的人物和主角提前产生交集，高潮过后正式过渡时读者已经有期待。

**势力延续**：旧地图主角接触过的势力 / 组织，在新地图里要延续（比如旧地图的某门派在新地图有分号）。让目标横跨两个地图，读者换地图时有耐心。

- 禁忌：新地图初期给主角设计高地位 → 没有危机 → 没有期待感 → 相当于白换地图
- 补充：战力不能断层——主角是筑基，就别让元婴级的角色出来晃；比主角高一级的最多露个面
- 适用：玄幻、都市、升级流的换地图节点
