## 四、简介写法分析（28 本全文拆解）

同人简介和原创简介的写法**完全不同**。原创简介卖"悬念"，同人简介卖"认领"。以下 6 条规律按出现频率排序。

### 规律 1：圈层共识梗前置——简介第一屏就要"对上暗号"

同人读者点开简介，要确认的第一件事是"作者是不是自己人"。所以简介里直接塞原作粉丝才懂的梗：

- 《龙族：路明非的弹幕许愿机》："【狠狠拷打婶婶！】【挖赵孟华的墙角】【和绘梨衣结婚】"——全是龙族粉的老梗
- 《战锤：我也要坐黄金王座吗？》：许愿"无尽寿命+第一梯队力量+亿万信徒+什么也不用干坐着就行"——战锤粉秒懂这是黄金王座地狱笑话
- 《斗罗：我，最后的天灾》："迈巴赫的灯特别耀眼""邪魂师的米奇妙妙屋"
- 《只想找份工作，然后海军大将了》："我拒绝加班"——海军本部加班文化梗

**公式**：读者共识梗 = 免费的情绪共鸣 + 零成本的信任建立。不懂梗的人不是目标读者，直接筛掉。

### 规律 2：标注式降门槛——直接回应同人读者四大焦虑

同人读者点开一本新书有四个焦虑：会不会太监？不懂原作能看吗？是不是 AI 文？会不会炒股（CP 党争）？成熟作者直接在简介里挂标注回答：

| 焦虑 | 标注实例 |
| --- | --- |
| 太监 | 【已有高订四万、均订一万四完结战锤同人】【已完本一万四千均海贼文】 |
| 门槛 | 【没了解过战锤的读者也可看】【当作传统游戏小说看问题不大】 |
| AI 文 | 【纯手写】【柯南同人十年老梆子】 |
| 炒股/毒点 | 【多女主】【不炒股】【单女主】 |

**结论**：同人简介的标注区不是装饰，是转化率工具。新人作者没有成绩背书时，至少要挂"不炒股/单女主/完本保证"这类承诺型标注。

### 规律 3：金手指从原作设定里长出来——不是外挂，是"这个世界本来就该有的东西"

| 书 | 金手指 | 与原作的缝合点 |
| --- | --- | --- |
| 海军本部？海贼本部！ | 反转系统：把角色阵营反转换积分 | 海贼的核心主题就是阵营与立场的错位 |
| 我绑定了夏弥 | 绑定对象变强=我同步变强 | 直接绑定原作角色夏弥，感情线+升级线合一 |
| 生肖符咒 | 12 符咒劈成 6 份，每个世界分两枚 | 成龙历险记的道具体系×同时穿越结构 |
| 万界词条 | 升级得词条，词条全是各 IP 能力 | 基因锁（无限恐怖）开篇，后续【诡秘之主】【大成圣体】 |
| 米花工藤新一 | 扮演系统：扮演工藤新一/雪莉/假面超人 | 柯南世界的"扮演"主题（怪盗基德易容） |

反例是没有缝合的"带系统穿火影"——《火影：每年一个金手指》简介直接用主角口吻自嘲这件事："带个破系统就叫开挂？……再来一挂！一年一挂！"把"系统烂大街"的槽点变成卖点。

### 规律 4：名场面预告——同人读者要的不是悬念，是"名场面保证"

原创文简介藏后期，同人简介**直接剧透后期大场面**：

- 《宇智波葫芦娃》："身高万丈的巨人将须佐能乎当作黑色盔甲披在身上"
- 《路明非弹幕许愿机》："驾驶初号机，左手地爆天星，右手无限剑制，面前飘着岁月史书"
- 《我绑定了夏弥》："龙化的夏弥看着操控四种元素跟自己激情互殴的青梅竹马"

原理：同人读者的爽点之一是"看原作不可能发生的场面发生"。简介给出名场面 = 给读者一个"追到此处的理由"，本质是**超长期钩子前置**。

### 规律 5：身份/阵营错位——同人开篇第一钩子

| 书 | 错位 |
| --- | --- |
| 海军本部？海贼本部！ | 把海军本部变成海贼本部 |
| 游戏王：BOSS竟是我自己 | 收集卡组防身 → 蓦然回首我成了 BOSS |
| 说好成为骑士，阿斯塔特什么鬼 | 想当骑士 → 被帝皇征召进战锤40K |
| 我是祖国人的好大儿？ | 祖国人是反派 → 儿子镜头前吹"最伟大的父亲" |
| 花和尚从鸠摩智模版开始 | 小和尚 → 扮演大反派鸠摩智 |

和原创文的错位金手指（见 [设定-错位金手指](../tropes/设定-错位金手指.md)）同源，但同人多一层：**错位对象必须是原作里读者熟悉的东西**，读者才能 0.5 秒内 get 反差。

### 规律 6：清单体结构——让读者快速确认"我的 IP 在不在里面"

多 IP 综漫文的简介大量用清单：

- 《生肖符咒》：六个世界×两枚符咒的分配表
- 《从骨王开始征服综漫世界》：已穿世界清单【Overlord（完成）—全职猎人（完成）—哥杀（完成）—海贼王（进行中）】
- 《诡秘命途行者》："已涉及世界：诡秘之主、崩铁、咒术回战、一拳、法环、RE0、龙族、游戏人生、overlord"

清单的隐藏功能：**连载进度展示**（"海贼王（进行中）"= 告诉读者写到哪了）和**排雷**（清单里没有的 IP 粉丝直接划走，不浪费双方时间）。

## 五、对本项目的启示

1. **战锤40K 是当前同人蓝海**：样本内 4–5 本，两本冲上月票榜前 130，且编辑在三江持续给量。门槛是战锤设定复杂，但《超凡帝国》《黄金王座》都证明了"伪战锤+降门槛标注"可行。
2. **红楼是隐性同人的安全区**：4 本全走历史分类，不吃同人分类的流量限制，读者基数极大（公有领域无版权风险）。
3. **"同时穿越+多 IP 缝合"结构已绑定同人赛道**：样本内 6+ 本，且都挂生肖符咒/词条/命途这类"分配清单"式金手指。参见 [结构-同时穿越](../tropes/结构-同时穿越.md)。
4. **简介公式（同人专用）**：圈层暗号（第一屏）+ 承诺型标注（完本/不炒股）+ 名场面预告（超长期钩子）+ 错位钩子（第一句）。
5. **新人慎入综漫**：需要同时懂多个 IP，且读者是各 IP 粉丝的交集——写崩一个世界就掉一批读者。单 IP 同人（红楼、战锤、斗罗）更适合第一本。
