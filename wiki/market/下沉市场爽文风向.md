# 下沉市场爽文风向

- 类型：市场 / 节奏 / 读者偏好
- 核心机制：2025 年前后起点生态的几个明确趋势，决定了新人如何定位自己的作品
- 五条可执行判断：

**1. 小白爽文 > 苦大仇深**：当前读者难以接受虐主、难以压主角制造爽点；先抑后扬除非写得好，否则谨慎。纯爽文市场更好。

**2. 读者有道德洁癖**：接受度变低，不喜欢主角做坏事 / 被做坏事。轻松爽一点的剧情胜出。

**3. 下沉市场对热点敏感度高**：作者需要有网感，能蹭到热点梗和热点事件。

**4. 漫剧改编成本降低**：下沉市场网文 + 漫剧双向引流，后续可能是网文承载流量的一个方向。

**5. 爽文需要新噱头**：存量市场下老套路很难吸引到小白；小白文也需要有自己的特色、新的噱头（卷了）。

- 禁忌：新人一上来写深度 / 苦大仇深 / 纯逻辑烧脑——容易没读者，也浪费产能
- 适用：所有新人作者的首本、前两本定位参考

## 经典下沉市场开篇配方

> 来自起点编辑星河："开局校花、胖子死党、高武异能、灵气复苏、世界变异。"

这套组合经过市场验证，新人直接套用：

| 元素 | 作用 | 为什么有效 |
| --- | --- | --- |
| 开局校花 | 情感钩子 | 下沉市场读者吃"被校花看上"的代入感 |
| 胖子死党 | 喜剧 + 信息差 | 胖子负责搞笑和递信息，主角负责酷 |
| 高武异能 | 爽点引擎 | 打架升级是下沉市场最稳的爽点 |
| 灵气复苏 | 世界观钩子 | 一句话铺完世界观，不用解释 |
| 世界变异 | 冲突来源 | 变异制造危机，推动剧情 |

**注意**：配方是骨架，不是全部。套用时必须加自己的"新噱头"（见趋势 5），否则和同质化作品卷不动。

## 新人避坑题材

> 来自起点编辑星河："新人不要写御兽文、克苏鲁、赛博、悬疑、仙界直播，这些都不构成卖点！"

| 题材 | 为什么不适合新人 |
| --- | --- |
| 御兽文 | 受众窄，且需要大量怪物设计，新人驾驭不了 |
| 克苏鲁 | 门槛高，读者需要懂设定，下沉市场不吃 |
| 赛博朋克 | 同上，设定门槛高，且容易写成"炫技" |
| 悬疑 | 节奏慢，追读率低，推荐机制不友好 |
| 仙界直播 | 市场已饱和，且直播元素在起点不吃香 |

**新人首选题材**：都市异能、高武、修仙升级、历史穿越、轻松日常——这些是下沉市场的基本盘。
