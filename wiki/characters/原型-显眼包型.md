# 显眼包型

- 原型名：显眼包（爱出风头 / 人群中最扎眼的人）
- 一句话：在一群正常严肃的人中间，耍宝耍得最突出、最出风头的那个人。
- 读者默认预期（自动加载的设定包）：
  - 走到哪都是焦点，行为夸张、声音最大
  - 不怕丢人，甚至有点享受丢人
  - 干的事往往不合时宜，但他说"气氛组就位"
  - 褒义化之后：活力外溢、可爱、能活跃气氛
- 反差玩法：
  - A 靠谱型：看着最不靠谱的显眼包，关键时刻是唯一站出来的
  - B 孤独型：越显眼越孤独，热闹是表演，独处才是真实（情感线）
  - C 掩护型：显眼是为了把所有人的注意力吸走，方便队友办事
  - D 反转型：大家以为他在耍宝，其实他在传递暗号
- 起点样本：
  - 《半岛：你不打游戏，泡什么爱豆》——嘴上放狠话、回家被堵门的反差
  - 《洪荒种田：开天第一道光》——项东"死不了就作死"，主动当洪荒最显眼的那个
- 小说用法：
  - 团队气氛组：负责在压抑剧情里给读者喘气的出口
  - 主角外壳：显眼包 + 真本事，是"乐子人主角"的低配版
  - 反派：显眼包型反派容易被记住，但威慑力弱
- 禁忌：
  - 只显眼不推进剧情 → 变成纯搞笑工具人
  - 显眼包太多 → 全员吵，读者疲劳
  - 把"显眼"写成"烦人" → 读者反感
