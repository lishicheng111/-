# 嘴硬打脸型

- 原型名：嘴硬（死鸭子嘴硬 / 立 Flag 型）
- 一句话：嘴上说最狠的话、立最满的 Flag，转头就被现实精准打脸，而且打完还要继续嘴硬。
- 读者默认预期（自动加载的设定包）：
  - 口头禅是"女人只会影响我拔刀的速度""我这辈子不可能……"
  - 说完立刻出事，而且事情精准地打在他说过的那句话上
  - 被打脸后不认输，换一套说辞继续嘴硬
  - 读者全程在等"什么时候翻车"
- 反差玩法：
  - A 半章打脸型：立 Flag 后不超过半章就翻车（节奏最快）
  - B 延迟打脸型：Flag 立了十几章才回收，回收时读者拍大腿
  - C 嘴硬真香型：嘴上嫌弃，行动上比谁都上心（情感线）
  - D 反向利用型：靠嘴硬激将对手，对手真上钩了
- 起点样本：
  - 《半岛：你不打游戏，泡什么爱豆》——程澈"单身保拔刀速度"，回家被爱豆拿棒球棍堵门
  - 《虐菜就会变强？我连夜加盟中超》——林风"故作轻松"，被全队当励志片看
- 小说用法：
  - 主角人设：低成本高回报，几乎每章都能用
  - 喜剧配角：负责立 Flag，主角负责看他翻车
  - 恋爱线：嘴硬真香是现成的感情推进器
- 禁忌：
  - 打脸间隔太长 → 读者忘了 Flag 是什么
  - 每次都是同一句式 → 读者预判，笑点失效
  - 只嘴硬不做事 → 变成纯小丑
