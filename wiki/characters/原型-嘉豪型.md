# 嘉豪型

- 原型名：嘉豪（隔壁班嘉豪 / 爱装型 / 中二装酷型）
- 一句话：全黑穿搭、黑口罩、虚空打碟、慢动作走路，一门心思想营造"酷炫神秘"，实际用力过猛。
- 读者默认预期（自动加载的设定包）：
  - 黑卫衣 + 黑口罩 + 帽子，全身黑
  - 公共场合突然进入"表演模式"：打碟、慢动作、耍帅
  - 自我感觉是神秘大佬，旁人看着像在耍猴
  - 说话带中二味，喜欢用"格局""气场""你们不懂"
- 出处：2024 年一位中学生在教室模仿 Alan Walker 打碟的视频，"隔壁班嘉豪"；2026 年爆火，全网刷屏（约 125.7 亿次讨论），已成"装腔作势、用力过猛"的代名词。
- 反面细节：这个梗已经高度标签化，带有**负面色彩**（哗众取宠）。写正面角色时要慎用。
- 反差玩法：
  - A 真大佬型：装得最凶的嘉豪，其实是唯一能打的那个（反差：装不是装的，是真有）
  - B 社死型：每次耍帅都被现实精准打脸（标准喜剧配角）
  - C 自嘲型：主角自己认领"我就是嘉豪"，用自嘲消解装逼的油腻感
  - D 掩护型：故意装成嘉豪吸引注意，掩护真正在办事的队友
- 起点样本：
  - 《半岛：你不打游戏，泡什么爱豆》——主角嘴上"女人影响我拔刀的速度"，典型嘉豪式嘴硬
  - 《娱乐：这个导演爱吃软饭！》——"三字真言：不主动，不拒绝，不负责"的装逼人设
- 小说用法：
  - 喜剧配角首选：负责装逼、翻车、被主角一句话拆台
  - 反派小头目：装腔作势，被主角随手秒掉，爽点成本极低
  - 主角外壳（慎用）：必须配自嘲或真本事，否则读者反感
- 禁忌：
  - 当主角又不给反差 → 读者觉得油腻、想弃书
  - 装逼翻车写得太频繁 → 变成重复段子
  - 用这个词直接给角色命名 → 太出戏，容易过气
