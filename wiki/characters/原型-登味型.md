# 登味型（中登 / 爹味）

- 原型名：中登 / 老登 / 登味（好为人师、爱说教、固执、跟不上时代）
- 一句话：一张口就是"我吃过的盐比你吃过的饭多"，热衷于指导年轻人、讲大道理、看不惯新东西。
- 读者默认预期（自动加载的设定包）：
  - 习惯性说教，三句话不离"想当年"
  - 固执己见，听不进新观点
  - 爱教育人，哪怕没人问他
  - 实际上心不坏，只是表达方式让人窒息
- 辈分梗背景（2026 流行）：
  - 85–94 称"老登"，95–99 称"中登"，00–05 称"小登"
  - 年轻人开始**主动认领**"中登"，用自嘲消解爹味
- 反差玩法：
  - A 自嘲型：主角自认"我就是个中登"，用自嘲抵消说教的油腻
  - B 真香型：嘴上说教，行动上真把小辈护在身后
  - C 反向型：小年轻满嘴登味，老前辈反而很潮（代际错位）
  - D 重生型：35 岁中登重生回大一，用登味经验降维打击（《牛来！从小散满仓到资本新登》罗诚）
- 起点样本：
  - 《牛来！从小散满仓到资本新登》（四季豆炒五花肉）——35 岁"中登"重回大一，满仓梭哈
  - 《战锤：火蜥蜴的锻造之王》——奥恩接受采访一本正经讲"伏尔甘偏商务，我偏运动"，标准大佬式爹味
- 小说用法：
  - 长辈/师父配角：提供经验、制造代沟笑点
  - 主角外壳：重生/穿越的中年灵魂，用登味当反差（身体年轻，说话老气）
  - 反派：爹味说教型反派，读者讨厌成本极低
- 禁忌：
  - 主角纯爹味不自我调侃 → 读者反感
  - 说教段落太长 → 直接劝退
  - 用"登"当骂人话硬贴标签 → 出戏
