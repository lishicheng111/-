# 摆烂作死型

- 原型名：摆烂 / 作死 / 躺平（不争不抢、破罐破摔、主动找事）
- 一句话：别人拼命往上爬，他主动往下躺；躺不明白就干脆作死，结果越作越强。
- 读者默认预期（自动加载的设定包）：
  - 口头禅"算了""随便""累了""毁灭吧"
  - 拒绝内卷，能躺就躺，能躲就躲
  - 被逼到绝路时，选择"既然活不了那就作个大的"
  - 看起来丧，其实是一种对抗内卷的清醒
- 反差玩法：
  - A 越摆越强型：摆烂反而踩中系统判定的隐藏奖励（洪荒项东，死不了就作死，作死反而成神）
  - B 假摆真卷型：嘴上摆烂，背地里比谁都努力（社畜共鸣）
  - C 摆烂救世型：全世界都在卷，只有他躺平，结果躺成了唯一清醒的人
  - D 作死反杀型：主动去惹最不该惹的人，反而被对方赏识
- 起点样本：
  - 《洪荒种田：开天第一道光》（滴茶）——项东，三无穿越者，无系统无老爷爷，死不了就放心作死
  - 《虐菜就会变强？我连夜加盟中超》——反向金手指，越虐菜越强，本质是"奖励摆烂"
- 小说用法：
  - 解压文主角：给被内卷压垮的读者提供情绪出口
  - 反套路开篇：所有人都在争，主角第一个说"我不玩了"
  - 配角：负责在紧张剧情里喊"要不咱算了吧"
- 禁忌：
  - 摆烂没有代价 → 变成无脑爽，读者很快就腻
  - 主角真的一点不推进剧情 → 读者弃书（摆烂是姿态，不是不作为）
  - 丧过头 → 压抑，失去解压功能
