# 人机型

- 原型名：人机（人机感 / 人机校花 / 人机男配）
- 一句话：说话做事像按程序运行的 NPC——认真回应、字正腔圆、零情绪波动、高度可预测。
- 读者默认预期（自动加载的设定包）：
  - 说话一字一顿、像朗读稿子、没有语气词
  - 有问必答，但答得机械、答非本意
  - 不懂玩笑、不懂暧昧、把客套话当真
  - 社交上"礼貌但冰冷"，不是高冷，是像没装情感模块
- 标志性符号：
  - 自我介绍用书面语："大家好，我叫 XX，希望在接下来的日子里和大家好好相处"
  - 回复永远"哦""嗯""好的""收到"
  - 按字面理解别人话，认真执行字面指令
- 反差玩法：
  - A 大神型：现实里人机，游戏/专业领域是大爹（《清冷校花？不，你是抽象圣体》徐子珊：现实说话像朗读机器，打游戏是"游戏大爹"）
  - B 内心戏型：外面人机，内心疯狂吐槽，读者看内心独白笑疯
  - C 情感最浓型：嘴上人机，行动上默默把人照顾到极致（情感线专用杀器）
  - D 把夸当贬型：她把"你个人机"当夸奖说出口（认知错位）
- 关键区分：**人机 ≠ 高冷**。高冷是"不理你"，人机是"认真理你但答得像程序"。
- 起点样本：
  - 《清冷校花？不，你是抽象圣体》（是心非，都市/日常文/单女主/思想迪化）——标签【抽象系校花】
  - 《我是机器人，最好别惹我！》（贰柒柠）——物理意义上的人机主角
- 小说用法：
  - 女主：清冷校花外壳 + 人机说话方式 + 大神内核，适合恋爱日常文
  - 男主：人机式理工男，配一个抽象/话痨配角当对照组
  - 配角：负责制造"他怎么什么梗都不懂"的笑点
- 禁忌：
  - 只写机械不写反差 → 读者觉得是背景板
  - 人机感写成"失智" → 变成降智角色
  - 全篇都是人机对话 → 阅读疲劳，必须有破功时刻
