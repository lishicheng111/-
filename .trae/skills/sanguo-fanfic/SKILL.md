# 三国同人创作系统（sanguo-fanfic）

## 一句话定位

**三国同人不是"写一个三国背景的原创故事"，而是"让读者认识的那个三国，因为一个他隐约听过的人而偏转"。**

读者买的不是世界观，是**身份期待感**：看到"魏讽""张泉""刘伟"这类名字，老读者会心头一动——"这人历史上不是死了吗？"这一动，就是追更的理由。

## 当前项目已锁定（2026-11-11）

| 项 | 决定 |
|---|---|
| 主角 | **魏讽本人**（字子京，沛人，钟繇西曹掾；史载 219 年谋袭邺被诛——本书设定为**被诬**，主角要避死局并高升） |
| 史实轨 | **正史为骨、演义为肉**；两线冲突以正史为准，名场面与人物气质借演义 |
| 路线 | **君主立宪（周召共和）**：表面在魏国做政治博弈，暗中组建寒门武装；阻止曹丕 220 年称帝，最终以《邺城约法》实现"汉献帝虚君、丞相府/议政院执政" |
| 改线 | **按卷递进：小 → 中 → 大**；最后一卷才动"曹丕称帝"这个锚点 |
| 外部压力 | 关羽襄樊之战只制造**恐慌与窗口**，不写成关羽能打赢、也不写成主角通敌 |
| 第一盟友 | **张泉**（张绣之子，降将集团代言人，做"面子"）+ **钟繇**（同盟，非靠山，会自保） |
| 动员方式 | 煽动 / 辩论 / 逐个说服关键角色 / 组建"约法派"同盟；借政治上位机制，不借意识形态 |
| 兵源 | 多源分阶段：游侠市井（情报）→ 屯田客（基干）→ 流民 / 州郡兵（规模），不碰禁军 |

> 这几项是当前默认值，用户改口时以当场表态为准，并更新本表。

## 何时触发

- 用户要写/策划/续写三国同人、三国网文、历史穿越文
- 用户给出一个新主角、新身份，要求判断能不能写、怎么切入
- 用户提供"写作心得"，需要沉淀为规则
- 用户要求拆解起点/番茄的三国竞品、找差异化空位
- 用户要求检索史料、野史、名场面、官职、物价等创作素材

## 七条不可违背（详见 `references/01-创作宪法.md`）

1. **身份必须可考**：姓名、籍贯、官职、结局，至少三项能在《三国志》及裴注/《后汉书》/《资治通鉴》里找到落点。野史补白可以，凭空造人不行。
2. **主角必须冷门**：大众第一反应能说出五个梗的角色，一律不做主角。冷门但有钩子，才是蓝海。
3. **名场面是 KPI**：每 5–10 章必须让读者撞见一个他认识的人或事。蹭不到名场面，就不是三国同人。
4. **时间线是轨道**：每个情节都要能回答"这是哪一年、谁在哪、离下一件大事还有多久"。
5. **改线必有代价**：主角改变历史，必须付出关系、身份、道德或寿命上的代价；且影响要有延迟，不能一章改完天下大乱。
6. **不写边疆种田**：种田只能当手段（粮道、军械、屯田制度），不能当主舞台；主线永远在权力中心的人和局上。
7. **计谋必须有历史原型**：主角的每一个计谋、每一步布局，都要能追到古今中外的真实原型，不得自行编造。先填"计谋卡"，战略原型 + 手法原型双层溯源，2–3 个原型拼接，单个计谋最多 3 个。详见 `references/09-计谋原型库.md`。

## 工作流 A：从零到一卷

1. **定身份**：按 `references/02-身份工程.md` 的四条路径选身份，先写"身份卡"（见模板）。过冷门度分级，排除 C 级热门角色。
2. **定时间窗**：在 `references/03-时间线与名场面台账.md` 找切入点，优先选"大事前 6–18 个月"的缝隙期，天然带倒计时。
3. **定势力位**：按 `references/04-权力中心生存学.md` 回答"谁保你、谁怕你、谁需要你"，确定主角在决策链第几排。
4. **定改线幅度**：本卷允许毁掉 1 个名场面，必须保留 2 个名场面；写下代价与延迟回收点。
5. **出卷纲**：每 5 章一个小名场面，每 15 章一次权力位阶变化，每卷末改写一个历史结局。

## 工作流 B：用户给"写作心得"时（核心交互）

**不要直接附和，也不要直接写入文件。先反问，再入库。**

1. 用 `references/07-追问问题库.md` 的"五问 + 三层追问"，一次只问 2–3 个最关键的，别审问。
2. 把用户回答提炼成**可执行规则**（不是复述原话），标注反例与落地方式。
3. 追加到 `references/05-写作心得库.md`，编号 `R-xxx`，**只追加不覆盖**；若新规则与旧规则冲突，在条目里写"修订 R-xxx"并说明。
4. 同步检查 `SKILL.md` 的"七条不可违背"是否需要升级。

心得条目固定格式：

```markdown
### R-012 ｜ 标题（YYYY-MM-DD）
- **原话**：
- **追问与回答**：
- **规则**：一句话可执行判断
- **反例**：什么样算写砸
- **落地**：用在卷纲/章纲/台词的哪一步
- **关联**：R-00x / 文件路径
```

## 工作流 C：定期素材检索

按 `references/06-素材检索与素材卡.md` 执行：检索 → 核验 → 写成"素材卡" → 追加到该文件的素材卡区。默认在"开新书""每 20 章""用户说更新素材"时触发。**史料标出处，野史标来源，不确定标"待考"，禁止把网文设定当史实。**

## 输出规范

- 谈身份：先给"身份卡"，再给"读者第一秒会想到什么"。
- 谈剧情：必须带年份、地点、在场人物、离下一件大事的天数。
- 谈改线：必须写"保留哪个名场面 / 毁掉哪个 / 代价是什么 / 几章后回收"。
- 谈计谋：必须给"计谋卡"——原型出处、战略层与手法层各学谁、情境成立理由、变形点、失败可能、代价。**写不出原型，就不写这个计谋。**
- 写正文：半文半白，对话不现代腔；名将台词要贴人物原味，不 OOC。
- 不写：边疆种田主线、无脑收名将、降智反派、把演义和正史混着用还不标注。
