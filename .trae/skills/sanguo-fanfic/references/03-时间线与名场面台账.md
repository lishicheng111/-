# 03 时间线与名场面台账

> 三国同人的骨架是时间线。读者可以容忍你改历史，不能容忍你不知道历史。

## 使用规则

1. **双轨标注**：动笔前先定"演义线 / 正史线"。两线冲突处（如华雄谁斩、草船借箭）必须在设定里选一个，并在文中保持，不能混用。
   - **本项目已定：正史为骨、演义为肉。** 大事件按正史，名场面与人物气质借演义；冲突处以正史为准，并在设定里标明"演义"。
2. **年月日**：卷纲写到年，章纲写到月，关键章写到日。建安年号与公元并用。
3. **倒计时**：每个卷纲开头写"距下一件历史大事：X 个月"。
4. **缝隙优先**：优先选"大事前 6–18 个月"的平静期切入，主角有时间布局，读者有耐心等爆点。

**蹭的精髓**：不是替代名将，而是让读者看到"名场面的背面"。主角是那个递刀、开门、传话、告密、救错人的人。

## 改线三原则

### 原则一：保锚点
每卷保留 2 个"必须按历史发生"的名场面，只改主角的参与方式。读者要的是"我认识的那个三国还在"。

### 原则二：延迟效应
```
第 1 次干预（小） → 第 2 次涟漪（中，10 章后） → 第 3 次偏转（大，30 章后）
```
第一次只改一个人的生死，不要把天下改掉。

### 原则三：代价显性
每次改命，写清代价：
- 关系代价：失去靠山/亲人/盟友。
- 身份代价：暴露穿越者/私生子/间谍身份。
- 道德代价：救一人，害十人。
- 时间代价：为了救人错过布局窗口。
