# 08 竞品拆解

> 目的不是模仿，是找**没人占的位**。写三国同人，最贵的不是文笔，是"这个身份还没人写过"。

## 一、拆解维度（每本竞品填一遍）

| 维度 | 要问的问题 |
|---|---|
| 身份 | 穿成谁？史书有名吗？冷门度 S/A/B/C？ |
| 时间点 | 哪一年切入？离哪件大事最近？ |
| 流派 | 辅佐 / 争霸 / 身份 / 谋士 / 武将 / 系统 / 种田 / 群像 |
| 金手指 | 信息差 / 系统 / 签到 / 词条 / 无 |
| 改线幅度 | 小改 / 中改 / 大改 |
| 名场面密度 | 几章一个？ |
| 关系网 | 靠谁起家？娶了谁？认了谁当老师？ |
| 权力位阶 | 从第几排到第几排？ |
| 感情线 | 单/多/无 |
| 毒点 | 读者骂什么？ |
| 数据 | 字数、推荐、完本/连载（实时查） |

## 二、起点三国的主要流派

### 1. 辅佐流
主角穿成谋士/幕僚，辅佐曹操、刘备、孙权。
- 卖点：跟着名场面走，读者熟悉。
- 风险：主角容易变成"工具人"，抢了军师戏份又被骂降智。
- 代表：《三国：昭烈谋主，三兴炎汉》（李翊辅佐刘备）。

### 2. 争霸流
主角自己当主公，从一城一地打到天下。
- 卖点：爽、格局大。
- 风险：容易滑向种田/基建；与三国名将的关系难处理。
- 代表：《覆汉》（公孙珣，辽东小吏之子，娶卢植女儿接入士族网）。

### 3. 身份流
穿成某人的儿子、早夭的世子、宗室、私生子。
- 卖点：身份期待感最强，读者一看就懂。
- 风险：热门身份已被占满（刘禅、曹昂、刘琦、刘封）。
- 代表：《三国之我不是曹昂》《三国：我叫刘琦》《三国：火腿泡面，我阿斗不用人扶吧》。

### 4. 谋士流
以智谋为核心，主角是军师型。
- 卖点：局中局、信息差。
- 风险：智斗写不好就降智；主角全知全能。

### 5. 武将流
主角是战将，靠武力与军功上位。
- 卖点：战场爽感。
- 风险：与关羽、张飞、赵云、吕布比武力，容易崩。

### 6. 系统 / 签到 / 词条流
金手指外显，降低写作门槛。
- 卖点：节奏快、爽点密。
- 风险：与"历史考据"气质冲突；读者两极。

### 7. 种田 / 技术流
发展生产、造水泥、炼钢、练兵。
- **用户明确禁区**：可以写粮道、军械、屯田制度，但不能把边疆开荒当主线。

### 8. 群像 / 考据流
重历史质感，多视角。
- 卖点：口碑好、耐读。
- 风险：门槛高、节奏慢、商业性弱。

## 三、案例卡

### 《覆汉》
- 身份：公孙珣，辽东小吏之子（非三国顶流，靠关系网起家）。
- 时间：黄巾将起未起。
- 流派：争霸 + 考据。
- 关键动作：娶卢植女儿，接入经学世家网络。
- 可学：**冷门出身 + 现成关系网**，不用编血脉也能进权力中心。
- 注意：自媒体转述，细节以原书为准。

### 《三国之我不是曹昂》
- 身份：现代青年曹修魂穿，顶替早夭世子曹昂。
- 流派：身份流 + 正史框架。
- 可学：用"早夭者顶替"制造身份悬念。
- 注意：曹昂是 B 级中热身份，已被写过，再写需强差异化。

### 《三国：我叫刘琦》
- 身份：刘琦（刘表长子）。
- 流派：身份流 + 权谋。
- 可学：荆州继承权之争，天然权力场。
- 注意：刘琦已有竞品，红海。

### 《三国：昭烈谋主，三兴炎汉》
- 身份：李翊，辅佐刘备。
- 流派：辅佐 + 谋士。
- 可学：从徐州到称帝的长线辅佐。
- 注意：辅佐流最怕"主角抢诸葛亮戏份"。

### 《三国：火腿泡面，我阿斗不用人扶吧》
- 身份：刘禅 + 签到系统。
- 流派：身份 + 系统 + 轻松。
- 可学：用"废物身份"做反差爽。
- 注意：刘禅是 B 级，且系统流与考据流气质冲突。

### 《游戏玩家闹三国》
- 身份：穿成刘备 + 游戏系统。
- 流派：争霸 + 系统。
- 可学：游戏化人才引进。
- 注意：穿刘备属于"改主公"，风险极高，容易被读者骂 OOC。

## 四、空白位（差异化机会）

> 以下位置，公开平台上少见以之为**主角**的作品。写之前仍需实时查榜确认。

| 空位 | 为什么好 | 风险 |
|---|---|---|
| **魏讽 / 邺城 219** | 权力真空、死亡倒计时、名将云集 | 史料少，需补白 |
| **陈祎（告密者）** | 道德困境极强，几乎没人写 | 主角不讨喜，需强笔力 |
| **张泉 / 刘伟（连坐者）** | 父辈血仇、兄弟对立 | 悲剧底色，爽点难做 |
| **郑袤（吹哨人）** | "我说了但没人信"的张力 | 主角被动 |
| **吕壹（东吴特务）** | 用诏书杀人，权力质感极强 | 阴暗，需分寸 |
| **暨艳（东吴反腐）** | 清议与世家对撞 | 冷门到读者不认识 |
| **二宫之争（吴）** | 储位、党争、族灭 | 后期人物知名度低 |
| **蜀汉东州派 / 益州本土** | 被忽略的视角，天然反北伐 | 需要读者有历史基础 |
| **淮南三叛** | 忠魏者的连续反叛，戏剧性强 | 后期冷门 |
| **士燮 / 交州** | 第四极，海路与贸易 | 容易滑向边疆种田（禁区） |
| **张鲁 / 汉中** | 政教合一，独特 | 宗教尺度需注意 |
| **许都政变 218（耿纪、韦晃）** | 天子脚下、衣带诏余波 | 与魏讽线相邻，可做前传 |

## 五、差异化公式

```
冷门身份（S 级）
× 权力中心（第 3 排，能看见第 0 排）
× 名场面背面（不抢高光，做变量）
× 改线代价（每救一人，害一人）
= 可写的三国同人
```

反过来，以下组合大概率扑：
- 热门身份 + 跟着原剧情走
- 冷门身份 + 边疆种田
- 原创角色 + 三国背景
- 全知主角 + 降智名将

## 六、榜单监测方法（定期执行）

1. 打开起点/番茄历史分类，按"三国"标签筛选，记录前 20 名的：书名、身份、时间点、流派、字数。
2. 重点看**新书榜**，不看总榜——总榜是红海，新书榜是风向。
3. 看简介第一句：现在流行"穿成谁"？
4. 看书友圈差评：读者在骂什么，就是下一本的卖点。
5. 记录到本节"案例卡"，每季度更新一次。
