# 05 写作心得库

> 用户会不定期给出写作心得。**每条心得必须先反问，再入库。** 只追加，不覆盖；冲突时写"修订"。

## 收录规则

1. 用户给心得 → 先按 `07-追问问题库.md` 问 2–3 个关键问题。
2. 用户回答后，提炼成"可执行规则"，不是复述原话。
3. 追加到本文件末尾，编号连续（R-001、R-002……）。
4. 规则若升级为"不可违背"，同步写进 `SKILL.md` 的六条。
5. 每条必须写"反例"和"落地"，否则不算入库。

## 条目模板

```markdown
### R-000 ｜ 标题（YYYY-MM-DD）
- **原话**：（保留用户原话，不要改写）
- **追问与回答**：
  - Q：
  - A：
- **规则**：一句话，能直接用来判断/改稿
- **反例**：什么样算写砸
- **落地**：用在身份卡/卷纲/章纲/台词的哪一步
- **关联**：R-xxx / 文件路径
```

### R-001 ｜ 同人是身份期待，不是原创架空（2026-11-11）

- **原话**：
  > "三国网文就是一个同人文……本质三国期待身份的期待感……但这是主角身份哈，不是让虚构一个角色出来，一定是二创而不是虚构原创。"
- **追问与回答**：
  - Q1：主角身份允许的"补白"边界在哪？野史里"刘备私生子""诸葛亮长子"这种，是可以直接当正史写，还是必须在设定里标"野史/架空"？
  - A：未单独确认。项目默认：正史为骨、演义为肉；正史无载的血脉补白，必须在设定中标"野史/架空补白"，不得写成正史。
  - Q2：如果用的是正史明确没有的人（如诸葛亮长子），你更希望"文中人物相信他是真的"，还是"读者知道这是假如"？
  - A：未单独确认。项目默认：文中人物可以相信，但设定层与作者注必须让读者知道这是"假如"。
- **规则**：主角必须是史书/演义/野史里**已有之人的身份位**（本人、子、弟、门生、属吏、同党），不得发明一个三国查无此人的新角色当主角。
- **反例**：穿越成"曹操流落在外的第七子曹某"，史书零记载、零关系网、零结局对照。
- **落地**：写身份卡时强制填"史书落点至少 3 项"和"二创四问"。
- **关联**：`02-身份工程.md` 第二节、第三节

### R-003 ｜ 主角要推进或改变时间线（2026-11-11）

- **原话**：
  > "由于你的存在，推进或改变了原时间线，没有边疆种田这样的写法。"
- **追问与回答**：
  - Q1：改线幅度你偏好哪一档——**小改**（救一个人、换一场胜负）、**中改**（换一个势力走向）、**大改**（换天下格局）？
  - A：已确认——**按卷递进：小 → 中 → 大**。第一卷只改个人生死与局部胜负，中段改派系走向，后段才动天下格局。
  - Q2："没有边疆种田"是**完全不许出现种田元素**，还是**不许把种田当主线**？粮道、屯田、军械这类手段能不能写？
  - A：待用户回答（当前按"可作手段、不可作主舞台"处理）。
- **规则**：主角必须真实改变历史，且改变有代价、有延迟；种田/基建只能当手段，不能当主舞台。
- **反例**：主角带着流民去塞外开荒三十章；或主角明知历史却全程装傻，只为让原剧情发生。
- **落地**：每卷写"改线卡"：保留哪个锚点、毁掉哪个、代价是什么、几章后回收。
- **关联**：`01-创作宪法.md` 第 6、8 条；`03-时间线与名场面台账.md` 改线三原则
