# 05 写作心得库

> 用户会不定期给出写作心得。**每条心得必须先反问，再入库。** 只追加，不覆盖；冲突时写"修订"。

## 收录规则

1. 用户给心得 → 先按 `07-追问问题库.md` 问 2–3 个关键问题。
2. 用户回答后，提炼成"可执行规则"，不是复述原话。
3. 追加到本文件末尾，编号连续（R-001、R-002……）。
4. 规则若升级为"不可违背"，同步写进 `SKILL.md` 的六条。
5. 每条必须写"反例"和"落地"，否则不算入库。

## 条目模板

```markdown
### R-000 ｜ 标题（YYYY-MM-DD）
- **原话**：（保留用户原话，不要改写）
- **追问与回答**：
  - Q：
  - A：
- **规则**：一句话，能直接用来判断/改稿
- **反例**：什么样算写砸
- **落地**：用在身份卡/卷纲/章纲/台词的哪一步
- **关联**：R-xxx / 文件路径
```

### R-009 ｜ 所有计谋与布局必须有历史原型（2026-11-11）

- **原话**：
  > "历史同人kill，主角所有的计谋，所有的布局必须参考古今中外的历史原型，不得自行编造。"
- **追问与回答**：
  - Q1 原型颗粒度：只要"战略原型"（这个局像哪一局），还是"战略 + 手法"都要？
  - A：**战略 + 手法都要**（双层溯源）。
  - Q2 允许拼接吗？拼几个？
  - A：**允许拼接，2–3 个原型**（主 1 + 辅 1–2），单个计谋不超过 3 个。
  - Q3 原型范围：只限中国史，还是含世界史？
  - A：**中国正史 + 兵书**为主；**世界制度史**可用；**演义/野史**单列标注；**近现代政治史**只取机制，且守红线（不写种族主义、不写灭绝、不美化独裁、不照搬极权、不用现代政党术语）。
- **规则**：
  1. **无原型不写**：任何一个计谋，先填"计谋卡"，写不出原型就不许进章纲。
  2. **双层溯源**：战略层（学谁）+ 手法层（怎么使），两层都得有出处。
  3. **2–3 个原型拼接**，主原型 1 个，辅助 1–2 个；超过 3 个视为缝合。
  4. **原型要匹配情境**：不是"这计很聪明"，而是"这个情境下，这个原型的条件成立"。
  5. **原型服务人物**：同一原型，魏讽使出来要像魏讽，不能像马基雅维利在讲课。
  6. **允许失败**：原型是历史里成功或失败的真实案例，主角照搬也可能失手，失败要写代价。
  7. **不冒充史实**：原型是结构参考，不得写成"历史上某人真这么干过"的伪史实。
- **反例**：
  - 主角凭空想出一条"如果他……就能……"的妙计，作者自己也说不出像哪一局。
  - 把《君主论》整章念给曹丕听，还自称"臣有一策"。
  - 一个计谋拼了五个原型，读者只觉得乱。
  - 原型与情境不匹配：拿"推恩令"去解决一个没有诸侯王的问题。
- **落地**：所有章纲先过 `09-计谋原型库.md`；每张计谋卡必须含"原型出处 / 情境成立理由 / 变形点 / 失败可能 / 代价"；`01-创作宪法.md` 铁律 13。
- **关联**：R-007（路线）、R-008（上位机制）、`09-计谋原型库.md`

## 冲突处理

- 新规则与史实冲突：以史实为准，在条目里标"待考/野史"。
