# 02 身份工程

> 三国同人的第一卖点是**身份期待感**。读者不是来看一个陌生人，是来看"这个身份的人"如何活。

## 一、身份期待感公式

```
期待 = 身份自带的关系网 × 史书已知结局的反差 × 读者心里的"如果"
```

拆开看：

1. **关系即剧情**：身份一确定，3–5 个强关系自动到位（血缘、师承、主臣、同乡、政敌）。不用解释，读者秒懂。
2. **结局即悬念**：身份自带"史书结局"。读者一边看一边等：他会不会死？怎么改？
3. **位置即冲突**：身份决定他一出场就站在谁的对立面。不用铺垫，矛盾自来。
4. **名字即彩蛋**：冷门名字被认出的一瞬间，读者会产生"我知道他"的优越感。这是同人独有的爽。

**反例**：原创一个"曹操流落在外的儿子曹某"。没有关系网、没有史书结局、没有彩蛋，读者只会觉得是套皮。

## 二、四条二创路径

### 路径 A：血脉补白（私生子 / 遗腹子 / 养子 / 早夭子 / 庶子）

适合用户提到的"刘备的私生子""诸葛亮的大儿子"这类。**注意：这是给已有名人补一个身份位，不是发明一个新角色当主角。**

必须自洽回答三个问题：
1. 史书为什么没写？（战乱失散 / 母亲身份低微 / 家族刻意隐瞒 / 记在别人名下）
2. 谁知道他的身份？（母亲、老仆、故人——这是前 10 章的信息差来源）
3. 认祖归宗的代价是什么？（被嫡系忌惮、被敌方利用、被史官抹去）

**红线**：不能把"正史明确没有"写成"正史其实有"，要在设定层标"野史/架空补白"。读者可以接受"假如"，不接受"篡改"。

### 路径 B：关系位补白（门生 / 故吏 / 乡党 / 家臣 / 使者 / 书佐 / 医者）

史书一笔带过的小人物，天然贴着大人物。
- 例：钟繇的西曹掾、曹操的军师祭酒、刘备的别部司马、孙权的书部。
- 优势：不用编血缘，直接吃现成的关系网；缺点：需要自己造"为什么史书没记住他"。
- 好用场景：主角是大人物身边的"透明人"，看得见一切，却改不动一切。

### 路径 C：失败者重来（最推荐）

历史上**已经失败、已经死了**的人。主角穿他，开局自带死亡倒计时。
- 魏讽、张泉、刘伟（魏讽案连坐）
- 耿纪、韦晃、吉邈、吉穆（许都纵火案）
- 王凌、毌丘俭、文钦、诸葛诞（淮南三叛）
- 李丰、夏侯玄、张缉（谋废司马师）
- 丁谧、毕轨、李胜、邓飏（曹爽党）
- 彭羕、廖立、李严、孟达、刘封（蜀汉失败者）
- 吕壹、暨艳、张温、吾粲、朱据（东吴失败者）

**为什么最好**：
- 读者看到名字就知道"他本来要死"——期待感直接拉满。
- 失败者天然站在权力中心的对立面，冲突不用编。
- 史料留白多，二创空间大。
- 改命本身就是主线，不需要额外设计目标。

### 路径 D：边缘宗室 / 降将 / 质子 / 宦官 / 女官

- 边缘宗室：刘虞、刘焉、刘璋、刘琦、刘琮、曹肇。
- 降将：张郃（热）、张绣、孟达、黄权、王平、夏侯霸。
- 质子/人质：诸侯子弟在许都、在邺城。
- 宦官/女官：更容易进内廷，但要注意尺度与史实。

## 三、二创 vs 原创：四问判定

| 问题 | 二创 | 原创（不合格） |
|---|---|---|
| 史书里有名字吗？ | 有 | 没有 |
| 有可对照的结局吗？ | 有（死/降/废/叛） | 没有 |
| 有现成关系网吗？ | 有（3 个以上） | 全靠编 |
| 读者会"哦，是他"吗？ | 会 | 不会 |

**两问答不上，就不是二创。** 宁可把主角降为"某人的门生"，也不要凭空造人。

## 四、冷门度分级

判定标准：把名字给一个"看过《三国演义》但不看网文"的人，他能说出几件事？

| 级别 | 标准 | 用法 |
|---|---|---|
| **S 极冷** | 说不出任何事，但史书有传/有载 | 首选。留白最大，钩子最强 |
| **A 冷门** | 能说出一个标签（如"刘封—不救关羽"） | 可用，需给新角度 |
| **B 中热** | 能说出三件事，网文已写过 | 慎用，必须强差异化 |
| **C 过热** | 大众偶像，同人默认不二创 | 禁用为主角 |

## 五、魏讽专题（用户点名方向）

### 史料底层（可考部分）

- 字子京，沛人（一说济阴）。
- 有"惑众才"，倾动邺都；相国钟繇辟为西曹掾。
- 荥阳任览与之友善；同郡郑袤断言："讽奸雄，终必为乱。"
- 建安二十四年（219）九月，潜结徒党，与长乐卫尉陈祎谋袭邺城。
- 未及期，陈祎惧，告之太子曹丕；曹丕诛讽。
- 连坐死者，一说数十人，一说数千人（《世语》与《通鉴》有差）。
- 钟繇坐此免官；王粲二子、张绣之子张泉、刘廙之弟刘伟等被牵连。

### 时间窗（天然倒计时）

219 年七月关羽北伐 → 八月水淹七军 → 曹操在长安/汉中方向，邺城由曹丕留守 → 九月魏讽案发 → 十月徐晃救樊 → 十二月白衣渡江。

**这是三国最密集的权力真空期**：外有强敌、内有储位之争、天子在许都、邺城空虚。主角只要站在这个窗口里，什么都不用编，戏自己会来。

### 五种主角方案

| 方案 | 穿成谁 | 核心问题 | 开篇钩子 |
|---|---|---|---|
| 1 | 魏讽本人（已锁定） | 被诬谋反、下狱待诛：如何自证、反用、高升？ | "距我历史上被处死，还有十七天。可我没反。" |
| 2 | 陈祎 | 历史说你告了密，你告不告？告了活，背叛；不告，一起死。 | "魏讽把刀放在我案上，说：事成，你我都封侯。" |
| 3 | 张泉 | 父亲张绣死在曹家手里，如今又要被曹家连坐。 | "曹丕杀我，不是因为我反，是因为我姓张。" |
| 4 | 刘伟 | 兄长刘廙是曹魏忠臣，自己却是叛党。 | "兄长在朝堂上保我，我在密室里签了名。" |
| 5 | 郑袤 | 你早就看穿魏讽会败，但没人信你。 | "我说魏讽必反，满座大笑；三个月后，他们跪着求我。" |

### 已锁定：魏讽本人 + 被诬翻案 + 君主立宪（当前项目）

**核心翻案设定**：史书所载"谋袭邺"在军事上不成立——邺城是魏都，重兵驻守；魏讽以文官西曹掾之身，联合长乐卫尉陈祎和若干徒党，根本攻不下邺城。所谓"谋反"，更像曹丕（或钟繇政敌）在 219 年权力真空中发动的**政治清洗**：先扣谋反帽子，再连坐数十至数千人，清掉汉室同情者与寒门才俊。主角要做的，是把这个"必死之局"翻成"自证 + 高升"的起点。

- **开局**：建安二十四年（219）九月，邺城，魏讽已被陈祎告发，下狱待诛。
- **三级目标**：不死 → 翻案 → 高升。
- **表面线**：在魏国体制内做政治博弈——钟繇、曹丕、士族、汉廷旧臣之间周旋；以"周召共和"为话术，主张天子垂拱、丞相府/议政院执政。
- **暗线**：以屯田客、流民、游侠、寒门中低层军吏为基础，组建不属于禁军的寒门武装。这是立宪的武力背书，也是最大的死罪。
- **外部压力**：关羽襄樊之战只提供"邺城恐慌 + 曹丕需要稳定"的窗口；不写成关羽能打过来，也不写成主角通敌。关羽败亡（219 十二月）后窗口关闭，主角必须已经拿到东西。
- **终局**：阻止曹丕 220 年称帝，把"禅让"改成"周召共和 + 邺城约法"；汉献帝为虚君，丞相府/议政院执政。
- **第一盟友**：张泉（张绣之子，降将集团的政治符号 / 代言人）；魏讽做他的谋主。钟繇是同盟，不是靠山——他会自保，关键时刻会弃车保帅。
- **动员方式**：煽动、辩论、逐个说服关键角色、组建"约法派"同盟；借政治上位机制，不借意识形态。
- **兵源**：游侠 / 市井（情报）→ 屯田客（基干）→ 流民 / 州郡兵（规模），不碰禁军。
- **红线**：不能写成主角真反；不能写通敌；不能一章翻案；不能让曹丕降智；不能把"君主立宪"写成现代政治讲座；不能把张泉写成纳头便拜的工具人。

### 翻案线的三种打法

1. **自证流**：查清陈祎告密的真实动机（被胁迫 / 被收买 / 被灭口），在曹丕面前自证，反手把幕后主使拖出来。风险：证据链难写，容易变成公堂戏。
2. **反用流**：不急着洗白，先认下"谋反"的帽子，让曹丕放松警惕；再用"连坐数十至数千人"激起的寒门、汉臣怨气，做自己的政治资本。风险：道德灰度重，读者可能不适。
3. **高升流**：主动替曹丕办脏活（清洗名单、安抚寒门、筹粮），换取升迁；官越做越大，暗线越铺越广。风险：主角容易变成"曹丕走狗"，需要后期反转。

### 魏讽线红线

- 不要洗白成"完美忠臣"。史料说他"奸雄"，就保留灰度。
- 不要写曹丕降智。曹丕能在储位之争赢曹植，政治嗅觉极强。
- 不要忽略"连坐数千人"的重量。主角每救一个人，都要有人替他死。
- 史料简略是优势也是风险：补白要自洽，别编出史料明确反对的事。

## 七、选角决策树

```
要写三国同人
├─ 想写大人物 → 不做主角，做配角（C 级黑名单）
├─ 想写新身份 → 回到"已有之人的关系位"（血脉/门生/子嗣）
├─ 想写改命 → 选"史书已死之人"（失败者重来，路径 C）
└─ 想写权力 → 选"离决策链最近的小人物"（魏讽/陈祎/郑袤/吕壹）
```
