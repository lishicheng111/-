# 06 素材检索与素材卡

> 用户要求：可定期自动从网上搜索历史同人文写作素材，总结沉淀。
> 原则：**先核验，再入库；史料标出处，野史标来源，不确定标"待考"。**

## 一、触发时机

- 开新书 / 定新主角时
- 每写完 20 章，做一次"名场面与史料补课"
- 用户说"更新素材""找点资料""看看别人怎么写"
- 写到一个不熟的年份、官职、地名、战役时

## 三、来源分级

| 级别 | 来源 | 用法 |
|---|---|---|
| **A 一手** | 《三国志》及裴松之注、《后汉书》、《资治通鉴》、《华阳国志》、《世说新语》 | 可直接引用，标卷次 |
| **B 学术/工具** | 中国哲学书电子化计划（ctext）、汉典古籍、维基文库、知网 | 可交叉验证 |
| **C 平台** | 起点、番茄、七猫、飞卢的榜单与简介 | 只看趋势与设定，不当史实 |
| **D 社区** | 起点书友圈、贴吧、知乎、NGA、豆瓣 | 找毒点、爽点、读者语言 |
| **E 自媒体** | 头条号、公众号、B站专栏 | 只当线索，必须回 A/B 层核验 |

**硬规则**：D、E 层的"史实"一律不回写进正文，除非在 A/B 层找到落点。

## 四、素材卡模板

```markdown
### 素材卡-000 ｜ 标题
- **类型**：人物 / 事件 / 制度 / 地理 / 毒点 / 竞品
- **出处**：（书名卷次 / URL）
- **可信度**：A 正史 / B 学术 / C 平台 / D 社区 / E 自媒体（待核验）
- **原文摘录**：
- **可用于**：（年份、地点、哪条线）
- **钩子**：（能怎么用）
- **风险**：（哪里不能碰）
- **状态**：已核验 / 待考
```

### 素材卡-001 ｜ 魏讽：邺城政变主谋

- **类型**：人物
- **出处**：
  - 《三国志·魏书·武帝纪》裴注引《世语》：<https://gj.zdic.net/shibu/109/6067.html>
  - 《资治通鉴》卷六十八·汉纪六十：<https://www.quanxue.cn/ls_zhengshi/zztj/zztj68.html>
  - 百科词条（C 层，仅作索引）：<https://m.baike.com/wiki/%E9%AD%8F%E8%AE%BD/2767634>
- **可信度**：A（正史 + 裴注）
- **原文摘录**：
  - "讽字子京，沛人，有惑众才，倾动邺都，钟繇由是辟焉。大军未反，讽潜结徒党，又与长乐卫尉陈祎谋袭邺。未及期，祎惧，告之太子，诛讽，坐死者数十人。"（《世语》）
  - "初，沛国魏讽有惑众才，倾动邺都，魏相国钟繇辟以为西曹掾。荥阳任览，与讽友善。同郡郑袤，泰之子也，每谓览曰：'讽奸雄，终必为乱。'九月，讽潜结徒党，与长乐卫尉陈祎谋袭邺；未及期，祎惧而告之。太子丕诛讽，连坐死者数千人。"（《资治通鉴》）
- **可用于**：建安二十四年（219）九月，邺城；魏讽线全部方案；许都政变（218）前传。
- **钩子**：才名倾都、钟繇举主、陈祎告密、郑袤预言、连坐数千；天然死亡倒计时。
- **风险**：史料极简，需大量合理补白；"连坐数十人"与"数千人"两说并存，建议在设定里选一说并注明；不要洗白成完美忠臣。
- **状态**：已核验（核心事实）；细节（党羽名单、政变日期）待考。

## 六、检索后的沉淀流程

1. 搜到 → 写素材卡（先标 C/D/E）。
2. 回 A/B 层核验 → 改状态为"已核验"。
3. 能用的，落到 `02/03/04` 对应文件的具体位置。
4. 与已有规则冲突的，写进 `05-写作心得库.md` 的"冲突处理"。
5. 每 20 章回看一次素材卡，删掉过时的。

## 七、检索红线

- 不把网文设定当史实。
- 不把自媒体标题当结论。
- 不编造史料原文；引用必须能点回出处。
- 不确定就写"待考"，不要装确定。
