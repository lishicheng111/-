# 09 计谋原型库

> 铁律：**主角所有的计谋、布局，必须有古今中外的历史原型；不得自行编造。**
> 执行口径：战略 + 手法双层溯源；2–3 个原型拼接；主原型 1 个 + 辅助 1–2 个；无原型不写。

## 一、七条执行规则

1. **无原型不写**：每个计谋先填"计谋卡"，没有出处的，不进正文。
2. **双层溯源**：战略原型（局）+ 手法原型（招），两层都要有出处。
3. **拼接上限 3 个**：主原型 1 + 辅助 1–2；必须标"主原型 / 辅助原型 / 改造点"。
4. **来源分级**：
   - A 中国正史 + 兵书（二十四史、《资治通鉴》《战国策》《孙子兵法》《韩非子》《管子》）
   - B 世界制度史（罗马共和、大宪章、光荣革命、美国制宪、明治维新等）
   - C 演义 / 野史（《三国演义》《世说新语》、地方传说）——单列，不得当正史
   - D 近现代政治史——只取机制，划红线
5. **不得冒充史实**：演义、野史、推演，必须在设定或作者注里标。
6. **原型服务人物**：不是把历史案例硬套，而是"这个人物、这个处境、这个资源，最可能用哪个原型"。
7. **允许失败**：原型是"别人用过的办法"，不是"必胜公式"。主角用错原型，要付代价。

```markdown

- 拼接方式：主原型 + 辅助原型；改造点是什么
- 本书映射：谁、何时、何地、对谁用
- 预期效果：
- 反噬 / 代价：
- 被谁识破 / 反制：
- 标注：正史 / 演义 / 野史 / 推演
- 自检：无原型？□ 双层？□ 拼接≤3？□ 有代价？□
```

## 五、近现代政治史（只取机制，划红线）

| 机制 | 案例 | 可取 | 不可取 |
|---|---|---|---|
| 危机叙事 + 群众动员 | 大萧条、战后危机 | 用危机聚拢人心 | 不写种族主义、不找替罪羊 |
| 统一战线 | 波兰团结工会、印度国大党 | 跨阶层联盟 | 不写清洗、不写一党独裁 |
| 合法外衣 | 明治维新、凯末尔改革 | 体制内改革 | 不美化政变 |
| 舆论控制 | 炉边谈话、宣传战 | 争夺话语权 | 不写谎言机器、不写洗脑 |
| 组织纪律 | 现代政党 | 核心圈、单线联系 | 不写极权组织 |
| 精英换血 | 明治、凯末尔 | 旧精英转化 | 不写大清洗 |

**红线**：不写种族主义、不写灭绝、不美化独裁、不照搬 20 世纪极权、不使用现代政党术语、不写具体酷刑 / 清洗细节。只借“怎么上位、怎么结盟、怎么立法”，不借“怎么害人”。

## 六、魏讽项目示例计谋卡

### 计谋卡-001 ｜ 卷一翻案

- **目标**：从“谋反死囚”翻成“被冤枉的能臣”，并保住一两个连坐者。
- **战略原型**：党锢之祸（清洗逻辑）+ 巫蛊之祸（构陷逻辑）+ 德雷福斯事件（翻案逻辑）。
- **手法原型**：缇萦上书（司法突破口）+ 陈平反间（离间告密者）+ 赵高指鹿为马（反面：构陷手法）。
- **拼接方式**：主原型 = 党锢之祸；辅助 = 巫蛊之祸、德雷福斯事件。改造点：主角不靠“英明皇帝”，靠“程序漏洞 + 舆论 + 关键人物”。
- **本书映射**：219 年九月，邺城狱中 / 公堂；对手是曹丕与钟繇。
- **预期效果**：不死，拿到第一个官位，寒门网络萌芽。
- **反噬**：救一人，害一人；陈祎或张泉必须有人付出代价。
- **被谁反制**：曹丕的清洗名单、钟繇的自保。
- **标注**：正史骨架 + 创作推演。
- **自检**：无原型？否 ｜ 双层？是 ｜ 拼接≤3？是 ｜ 有代价？是

### 计谋卡-002 ｜ 结盟张泉

- **目标**：拿到降将集团的政治代言与军中关系。
- **战略原型**：光武河北联盟（联姻 / 豪族）+ 三头同盟（利益同盟）+ 推恩令（分化）。
- **手法原型**：毛遂自荐（主动请缨）+ 信陵君窃符救赵（借兵 / 义气）。
- **拼接方式**：主原型 = 光武河北联盟；辅助 = 三头同盟、推恩令。改造点：张泉不是被感化，是被“降将集团无代言人”的利益驱动。
- **本书映射**：219 年十月后，邺城 / 张泉府。
- **预期效果**：张泉做“面子”，魏讽做“里子”；降将集团部分人观望。
- **反噬**：张泉一旦发现被利用，反目；曹丕会把“降将 + 寒门”看成结党。
- **被谁反制**：曹氏宗亲、钟繇。
- **标注**：正史人物 + 创作推演。
- **自检**：无原型？否 ｜ 双层？是 ｜ 拼接≤3？是 ｜ 有代价？是

### 计谋卡-003 ｜ 寒门武装

- **目标**：在不碰禁军的前提下，长出可用的武力。
- **战略原型**：马略募兵改革（兵源 + 忠诚）+ 曹操屯田（粮兵一体）+ 威尼斯十人委员会（组织纪律）。
- **手法原型**：商鞅徙木立信（信用）+ 吴起吮疽（同甘共苦）。
- **拼接方式**：主原型 = 马略募兵改革；辅助 = 曹操屯田、威尼斯十人委员会。改造点：分三步走，先游侠后屯田再州郡，不碰禁军。
- **本书映射**：219 年冬至 220 年，邺城周边屯田 / 市井。
- **预期效果**：情报网 + 基干 + 关键时刻的“存在感”。
- **反噬**：暗线暴露 = 谋反；屯田官、校事、曹丕的眼线。
- **被谁反制**：校事、吕虔一类的地方官、曹丕。
- **标注**：正史制度 + 创作推演。
- **自检**：无原型？否 ｜ 双层？是 ｜ 拼接≤3？是 ｜ 有代价？是

### 计谋卡-004 ｜ 阻止曹丕称帝

- **目标**：220 年禅让前夜，把“禅让”改成“周召共和 + 邺城约法”。
- **战略原型**：大宪章（限制王权）+ 光荣革命（虚君）+ 奥古斯都元首制（保留共和外壳）。
- **手法原型**：周召共和（话术）+ 王莽符命（反用谶纬）+ 推恩令（给士族好处）。
- **拼接方式**：主原型 = 大宪章；辅助 = 光荣革命、奥古斯都元首制。改造点：曹丕得实权、失帝号；汉帝得名位、失实权。
- **本书映射**：220 年，洛阳 / 邺城，曹操死后。
- **预期效果**：曹丕暂缓称帝，议政院成立，约法刻石。
- **反噬**：主角成为曹丕、士族、汉臣三方共同的眼中钉。
- **被谁反制**：曹丕 core（吴质、朱铄、司马懿等）、士族保守派、刘备 / 孙权。
- **标注**：正史骨架 + 世界制度史拼接 + 创作推演。
- **自检**：无原型？否 ｜ 双层？是 ｜ 拼接≤3？是 ｜ 有代价？是

## 七、反例（出现即重写）

1. **无出处的“天才计谋”**：主角灵机一动，想出一个史书里没有、现实里也不成立的办法。
2. **现代管理学术语**：KPI、OKR、SWOT、闭环、颗粒度——出戏。
3. **影视桥段**：《琅琊榜》《权力的游戏》《纸牌屋》的权谋，不是历史原型。
4. **把演义当正史**：空城计、草船借箭、三英战吕布，必须标“演义”。
5. **原型硬套**：三国没有的条件（报纸、政党、常备军、全国性学校），硬套近代原型。
6. **主角全知全能**：原型只是装饰，主角永远赢，没有代价。
7. **一计多原型但无主次**：拼了五个，谁也说不清主原型是谁。
