# 起点小说写作项目

目标：在起点中文网连载，实现月收入 10,000 元。

这不是一个"让 AI 帮我写小说"的仓库，而是一套**写作方法 + 素材库 + 生产流水线**：
每次拆书、每次写作、每次复盘，都会让库变厚一点，让下一章更好写一点。

## 快速开始

```text
请读取项目记忆，告诉我当前状态和下一步。
请拆解 raw/sources 里的这本书，提炼结构和爽点，写入 wiki。
请用选题技能评估我这个想法：……
请按 chapter-pipeline 写第 12 章。
请根据最近数据做一次复盘，指出问题并给调整方案。
```

## 目录

```text
AGENTS.md        Agent 操作协议（每次会话必读）
memory/          项目状态：目标、偏好、决策、待确认问题、工作日志
raw/             原始资料：拆书样本、竞品章节、平台规则截图
wiki/            编译后的长期知识：方法、题材、桥段、钩子、拆书分析
output/          交付物：选题、大纲、章节草稿、已发布存档、复盘报告
project/         具体作品目录（bible / characters / arcs / state / chapters）
skills/          可复用工作方法（立项、拆书、开篇、日更、复盘……）
```

## 怎么"养库"

1. 每拆一本书，至少产出：结构表 + 爽点表 + 钩子表 + 人设表。
2. 不同书重复出现的桥段，抽象成"变体"放进 `wiki/tropes/`。
3. 自己写废的章节不要删，放进 `wiki/analyses/` 做失败样本。
4. 每完成一卷，跑一次 `wiki-lint`，清理重复和过期内容。
