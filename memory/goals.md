# 目标与里程碑

## 终极目标

起点连载月收入 **10,000 元**。

## 收入反推（估算，待核实）

```text
月收入 ≈ 均订 × 当月更新章节数 × 单章订阅分成单价 + 全勤 + 月票/打赏
假设：单章 3000 字，作者分成后约 0.05–0.07 元/订阅/章
日更 2 章 → 每月 60 章
均订 3000 → 3000 × 60 × 0.06 ≈ 10,800 元/月（税前，未计老章持续订阅）
```

**因此核心可执行指标是：均订 3000；支撑指标是追读率与稳定日更。**

## 失败信号

- 连续 7 天断更 → 直接损失追读与推荐。
- 首卷追读率持续低于 30% → 开篇或核心循环有问题，需大修而非硬写。
- 写到 20 万字仍无稳定读者 → 停更复盘，换题而不是硬撑。
