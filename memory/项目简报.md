# 项目简报

- 项目类型：网络小说创作与连载
- 平台：起点中文网（中文）
- 商业模式：VIP 订阅分成 + 全勤/月票/打赏 + 后续版权
- 收入目标：**月入 10,000 元人民币**
- 项目形态：个人创作 + Agent 协作的知识工作环境
- 核心方法：库（可积累的写作知识）+ 技能（可复用的生产流程）
- 写作基础：签约过，成绩一般（有实战经验，重点补商业节奏与数据诊断）
- 每日产能：稳定 6000 字 / 天（≈ 2 章 × 3000 字/章）
- 首本策略：跟爆款，模仿精髓（先吃透赛道头部作品的结构与爽点，再在一个点上做微创新）
- 赛道状态：待定（用户将上传具体目标后确认）
- 当前阶段：方法论 v0.1 已建，等待赛道目标上传后进入 M1 选题与拆书

## 范围

- 包含：选题、世界观、人设、大纲、开篇、日更章节、数据复盘、拆书入库
- 不包含：代运营、刷数据、抄袭洗稿、多平台同步分发（暂定）

## 边界与约束

- 语言：简体中文
- 输出格式：Markdown 为主；需要投稿或打印时再转 docx
- 单章字数：2000–3500 字
- 保密：作品设定与未发布章节不对外

## 成功标准（第一年）

1. 完成一本 60 万字以上连载，且未断更。
2. 稳定签约并上架。
3. 均订达到 3000 左右，月收入接近 1 万。
4. 沉淀出可复用的选题、开篇、日更流程，第二本启动成本显著下降。
