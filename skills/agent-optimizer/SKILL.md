# Agent 优化器

## 何时用

- 用户连续纠正同类问题
- 同一流程重复执行 3 次以上
- 每 10 次工作会话 / 每卷结束
- 用户说"优化一下工作方式"

## 流程

1. 读 `memory/worklog/` 最近记录、`memory/重要决策.md`、`wiki/log.md`。
2. 统计：
   - 被纠正 ≥ 2 次的问题
   - 每次都要重复解释的偏好
   - 经常卡住的步骤
3. 生成**优化提案**（不直接改）：
   - 改哪条规则、为什么、改成什么
   - 影响范围
   - 风险
4. 用户确认后写入 `AGENTS.md` / 对应技能 / `memory/用户偏好.md`。
5. 在 `memory/worklog/` 记录本次优化。

## 约束

- 不删除已有规则，除非用户明确同意。
- 一次最多改 3 处，避免规则膨胀。
- 新规则必须可执行（能判断对错），不写"要写得好"这种空话。

## 产出

一份优化提案 + 确认后的变更记录。
