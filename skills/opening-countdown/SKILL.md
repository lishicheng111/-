# 倒计时开篇法

## 何时用

- 选题已定，要写第 1 章，想快速入戏
- 旧书开篇慢热、追读率低，需要重写
- 题材偏悬疑/无限流/末世/都市异能/玄幻前期

## 核心原则

**先给倒计时，再给世界观。** 读者进入书的第一秒看到的是"主角必须在 X 时间内解决 Y 事"，而不是"这是一个怎样的世界"。

## 倒计时四种来源（选一种）

1. 生命倒计时：中毒/受伤/被追杀，剩余时间明确
2. 任务倒计时：必须在某时间点前完成某事
3. 事件倒计时：不可逆转的事件即将发生
4. 规则倒计时：世界规则本身带时限（副本/秘境/试炼）

## 流程

### 第一步：定倒计时（3 行卡片）

写之前先填这三行，不填不许动笔：

```text
倒计时：还有 [具体时间量级，如"一炷香"/"三个时辰"/"七天"]
要解决的事：[主角必须做什么，如"抢到引魂灯"/"送出这封信"]
失败后果：[不解决会怎样，如"黑线到心就死"/"全家被灭"]
```

硬要求：
- 时间必须具体可感知，不许写"时间不多了"
- 时间量级在"几刻钟到几天"之间，太长没紧迫感，太短没操作空间

### 第二步：定世界观碎片（只留必需的）

列一张"倒计时期间必须透露的世界观清单"，原则：**只留解决倒计时所必需的，其余全部延后**。

每个碎片用"名词 + 一句解释"：
```text
- 引魂灯：照一次魂散一寸（主角要抢的道具）
- 黑线：从手腕爬到心脏就死（倒计时本身）
- 柴房：昨晚藏火折子的地方（主角的资源）
```

### 第三步：写第 1 章前 1000 字

结构（五段微缩版）：

1. **画面切入**（1–2 段）：主角当前处境 + 倒计时的具体呈现（黑线爬到哪、钟摆走了几下）
2. **压力明确**（1 段）：失败后果一句话点透
3. **资源亮出**（1–2 段）：主角手里有什么可用（道具/信息/能力），读者看到"有解"
4. **行动启动**（1 段）：主角开始动，读者跟着跑
5. **第一个小反转或小进展**（章末前）：让读者看到"倒计时在推进，但主角也在推进"

章末钩子：倒计时还在走，但情况变得更复杂了（敌人出现新动作 / 资源失效 / 时间比想象的少）。

### 第四步：自检（5 条，逐条过）

1. 前 300 字内出现主角 + 倒计时（具体时间）+ 压力来源？
2. 有没有出现"这个世界是……"这类百科式句子？→ 删掉
3. 每段世界观碎片是否都服务于"解决倒计时"？→ 不服务的删掉
4. 倒计时是否具体（可感知量级）？
5. 章末钩子是否让倒计时更紧迫，而不是解除？

### 第五步："陌生人测试"

把第 1 章前 1000 字单独读一遍，假装不知道这本书的任何信息，问自己：
- 我知道主角现在最急的事是什么吗？
- 我想看他怎么解决吗？
- 有没有哪句话是"作者在跟我解释世界观"？→ 有就删

两个答案都是"是"、第三个是"没有"，才算通过。

## 硬指标

- 前 300 字：主角 + 具体倒计时 + 压力来源 三要素齐全
- 前 1000 字：不出现任何"这个世界是 X"的百科句
- 世界观碎片 ≤ 5 个，每个 ≤ 1 句话
- 章末：倒计时仍在推进，且情况变复杂
