# 立项访谈

## 何时用

- 新项目启动
- 用户说"我想写小说但不知道从哪开始"
- `memory/project-brief.md` 或 `goals.md` 缺失

## 流程

1. 先读 `memory/` 现有文件，不重复问已知信息。
2. 依次问四类问题（一次问 2–4 个，不要连环轰炸）：
   - **方向**：男频/女频？题材倾向？最近读完的 3 本书？
   - **基础**：零基础 / 签约未起量 / 有完本 / 已有稳定收入？有无旧稿可诊断？
   - **产能**：每天能写多少字、多少小时？一年能断更几天？
   - **策略**：稳妥模仿爆款 / 差异化微创新 / 快速试错多开 / 长线精品？
3. 把答案写入：
   - `memory/project-brief.md`（背景与范围）
   - `memory/goals.md`（按产能重算收入模型与里程碑）
   - `memory/user-preferences.md`（题材、雷点、沟通偏好）
   - `memory/decisions.md`（关键选择）
   - `memory/open-questions.md`（没答上的）
4. 最后给出一页"立项结论"：推荐赛道、风险、下一步。

## 判定规则

- 日产 < 4000 字 → 收入模型必须按日更 1 章重算，并明确告知"均订要求翻倍"。
- 无法保证月更 25 天以上 → 先解决产能，不进入选题。
- 零基础 + 无阅读积累 → 先做 1 周拆书，再选题。

## 产出

`output/concepts/立项结论-v1.md`（含日期、状态、依赖来源）。
