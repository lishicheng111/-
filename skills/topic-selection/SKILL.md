# 选题评估

## 何时用

- 想开新书，有一个模糊想法
- 想换赛道
- 需要在 2–3 个选题之间做决定

## 流程

1. **提炼一句话卖点**，套公式：
   `[身份/处境] + [金手指/设定] + [终极问题] + [差异化钩子]`
2. **赛道体检**：
   - 目标读者与情绪需求
   - 同赛道在榜作品数量（供给）
   - 我的差异化来自哪里（经验/知识/视角/梗）
3. **引擎测试**：一句话说出"读者每 3 章能看到什么"。说不出来 → 淘汰。
4. **前三章预演**（每章 100 字以内）：
   - 第 1 章：困境 + 金手指 + 钩子
   - 第 2 章：首爽 + 世界观
   - 第 3 章：主线目标 + 强钩子
5. **风险清单**：题材政策风险、同质化、自己写不下去的地方、后期容易崩的点。
6. **打分**（1–5）：
   市场空间 / 差异化 / 个人可持续性 / 爽点可扩展性 / 开篇难度（反向）
7. 输出 1 个推荐方案 + 1 个备选，写入 `output/concepts/`。

## 判定规则

- 差异化 ≤ 2 且个人可持续性 ≤ 2 → 直接否掉。
- 开篇难度 5 → 先写测试稿，不直接立项。
- 三个选题分数接近 → 选"作者最想写"的那个，长篇靠热爱续命。

## 产出

`output/concepts/<选题名>-评估-v1.md`，含评分表与前三章预演。
