# 短视频段子拆解入库

## 何时用

- `raw/sources/` 新增短视频段子素材，或用户指定某个博主
- 需要给小说加笑点、小桥段、节奏变化，但现有桥段库不够用
- 用户说"帮我拆一下这个博主的段子"

## 与 source-ingestion 的区别

| 维度 | source-ingestion（拆书） | skit-ingestion（拆段子） |
| --- | --- | --- |
| 输入 | 小说正文（章节制） | 短视频段子（碎片化） |
| 分析单位 | 章/卷 | 单个段子 |
| 核心产出 | 结构表、爽点表、钩子表、人设表 | 段子样本库、结构模式、桥段零件 |
| 重点 | 长线节奏与人物弧线 | 单点笑点的机制拆解 |

## 输入

- 博主的视频链接、二创剧本、弹幕/评论区的名场面记录
- 至少 5–10 个段子样本，越多越能发现共性模式

## 流程

### 第一步：收集段子样本

1. 搜索博主的经典段子、名场面、高播放视频
2. 对每个段子记录：
   - 段子名（或一句话概括）
   - 一句话剧情
   - 关键台词/反转点
3. 整理成「段子样本库」表格

### 第二步：识别结构模式

对每个段子问三个问题：

1. **预期是什么？**（读者/观众以为会发生什么）
2. **实际发生了什么？**（反转点在哪）
3. **为什么好笑？**（落差来自哪里：身份错位？能力与目标不匹配？信息差？语体反差？）

把相同机制的段子归为一类，提炼出**结构模式**。常见模式参考 [逗比的雀巢-段子拆解](wiki/analyses/逗比的雀巢-段子拆解.md)：
- 经典解构反转、层层降级、双线互潜、身份突变、宏大小用、幻想现实错位、权力倒置、荒诞细节填充、新闻腔反差

### 第三步：抽取桥段零件

对每个结构模式，写成一个 `wiki/tropes/` 页面，包含：
- 类型、核心机制、压抑方式、释放方式
- 至少 2–3 个变体（每个变体给一个段子样本 + 一个小说转化示例）
- 适用题材、禁忌

叙事技巧类（语体、细节填充等）放 `wiki/craft/`，不放进 tropes。

### 第四步：写综合分析页

在 `wiki/analyses/<博主名>-段子拆解.md` 写完整分析，包含：
- 博主定位（内容形式、风格、受众门槛）
- 段子样本库（表格）
- 结构模式分析（每个模式给公式+样本+小说转化）
- 可复用机制提炼表
- 最值得抄的 3 个机制 + 最不该抄的 3 个毛病

### 第五步：登记

- 更新 `wiki/tropes/_index.md`、`wiki/index.md`、`wiki/来源映射.md`、`wiki/log.md`

## 质量门槛

- 每个桥段必须给**小说转化示例**，不能只停留在段子本身
- 变体不能只是换皮，要换**核心变量**（换目标、换场景、换关系）
- 必须标注"不该抄的毛病"，避免生搬硬套

## 产出示例

```text
《博主名》段子拆解
- 博主定位：搞笑短剧，抽象吐槽风，受众需懂游戏梗
- 段子样本：8 个
- 抽出机制：经典解构反转、层层降级、宏大小用
- 最值得抄：宏大小用（成本低、笑果稳）
- 最不该抄：梗太硬核（小说读者不一定 get）
```
