## 一、大时间线（建安二十三年十月 — 二十五年正月）

> 以《三国志·武帝纪》为骨架。**这一段是全书的"历史底噪"，主角知道个大概，但不知道细节。**

| 时间 | 事件 | 出处 |
| --- | --- | --- |
| 建安二十三年（218）十月 | 宛守将**侯音**反，执南阳太守，据宛 | 《武帝纪》 |
| 二十四年（219）**正月** | 曹仁屠宛，斩侯音；**夏侯渊**与刘备战于阳平，被杀 | 《武帝纪》 |
| **三月** | 曹操自长安出斜谷，至阳平；刘备因险拒守 | 《武帝纪》 |
| **五月** | 曹操引军还长安 | 《武帝纪》 |
| **七月** | 立夫人**卞氏**为王后；遣**于禁**助曹仁击关羽 | 《武帝纪》 |
| **八月** | **汉水溢，灌于禁军，军没**；关羽擒于禁、斩庞德，围曹仁；曹操遣**徐晃**救之；**关羽威震华夏，曹操议迁都以避其锐** | 《武帝纪》《关羽传》 |
| **九月** | **相国钟繇坐西曹掾魏讽反，免。** | 《武帝纪》 |
| **十月** | 曹操军还洛阳；孙权遣使上书，以讨关羽自效；曹操自洛阳南征关羽 | 《武帝纪》 |
| **十二月** | 关羽败走，曹仁围解 | 《武帝纪》 |
| 二十五年（220）**正月** | 曹操至洛阳；孙权击斩关羽，传其首；**庚子，曹操崩于洛阳** | 《武帝纪》 |

### 三个必须记住的时间锚点

1. **侯音反是二十三年十月，不是二十四年**。二十四年正月已被斩。
2. **八月关羽水淹七军**，是魏讽动手前一个月。这个时间差是全书张力的来源。
3. **九月魏讽案发**，十月曹操才回洛阳。所以案发时曹操不在邺城，主事的是曹丕。

## 三、时代生活方式

### 3.1 时间感：一天怎么过

| 项 | 内容 | 标注 |
| --- | --- | --- |
| 计时 | 十二时辰；官府用**漏刻**，城中击鼓报时 | 【史料】 |
| 作息 | **日出而作，日落而息**；夜间有**宵禁**，坊门关闭 | 【史料】 |
| 用餐 | **平民一日两餐**（朝食、餔食）；贵族可三餐 | 【史料】 |
| 夜晚 | 照明靠**豆灯、油灯**，灯火贵，普通人早睡 | 【推断】 |

> **写作可用**：宵禁是天然的"时间锁"——夜里不能上街，密谋只能在室内。

### 3.2 吃什么

| 类别 | 内容 | 标注 |
| --- | --- | --- |
| 主食 | **粟（小米）**为主，麦、稻次之；穷人吃**粝食**（糙米）、藜藿（野菜） | 【史料】 |
| 做法 | 煮（羹）、蒸（饭）、烤（炙）、生切（脍）；**没有炒菜** | 【史料】 |
| 调味 | 盐、酱、豉、醋、姜、花椒 | 【史料】 |
| 肉 | 羊、猪、鸡、鱼；**牛是耕畜，禁杀** | 【史料】 |
| 酒 | **醪酒**（浊）、**清酒**（贵）；宴饮必饮酒 | 【史料】 |
| 茶 | 尚未成为日常饮品，多为药用 | 【推断】 |

> **写作避坑**：不要写"炒两个菜""泡壶茶""来碗面条"——汉代都没有。

### 3.3 穿什么

| 身份 | 服饰 | 标注 |
| --- | --- | --- |
| 官员 | **袍、深衣**；佩**印绶**（比四百石：铜印黄绶） | 【史料】 |
| 士人 | 冠（进贤冠、帻）；宽袍大袖 | 【史料】 |
| 平民 | 短褐、布衣；戴巾帻 | 【史料】 |
| 鞋 | **履**（正式）、**屐**（日常） | 【史料】 |
| 颜色 | 有等级，但不如后世严格；黑色、赤色为贵 | 【推断】 |

> **写作可用**：魏讽是比四百石，**铜印黄绶**——这个细节一写，考据党立刻服。

### 3.4 住什么

| 项 | 内容 | 标注 |
| --- | --- | --- |
| 坐 | **席地跪坐**；有床、榻，但**没有椅子** | 【史料】 |
| 家具 | 案（小桌）、几、席、屏风 | 【史料】 |
| 墙 | 夯土墙、木构；富家有**瓦顶**，平民多**茅顶** | 【推断】 |
| 院 | 有院墙、门、井；士人宅常有**前院待客、后院居住** | 【推断】 |
| 厕 | 与猪圈相连（"溷"），是汉代常见形制 | 【史料】 |

> **写作避坑**：不要写"坐在椅子上""推开玻璃窗""点蜡烛"（蜡烛昂贵，多用油灯）。

### 3.5 怎么出行

| 方式 | 适用 | 标注 |
| --- | --- | --- |
| 步行 | 平民、短途 | 【史料】 |
| 牛车 | 士人常用，平稳但慢 | 【史料】 |
| 马车 | 贵族、官员 | 【史料】 |
| 骑马 | 军人、急使 | 【史料】 |
| 船 | 水路，邺城有漳水 | 【史料】 |

### 3.6 怎么说话：称谓与礼仪

| 场合 | 用法 | 标注 |
| --- | --- | --- |
| 自称 | 仆、愚、臣（对上）、某 | 【史料】 |
| 称人 | 足下、君、公、卿、先生 | 【史料】 |
| 称字 | 平辈、朋友之间称**字**，不称名 | 【史料】 |
| 跪拜 | 稽首（最重）、顿首、空首 | 【史料】 |
| 揖 | 长揖（平辈）、拱手 | 【史料】 |
| 座次 | 室内**东向为尊** | 【史料】 |

> **关键**：魏讽字**子京**。朋友叫他"子京"，下属叫"魏掾"，长辈叫他"子京"。**没人叫他"魏讽大人"。**

### 3.7 钱与物价

| 项 | 内容 | 标注 |
| --- | --- | --- |
| 货币 | **五铢钱**；谷、帛也当货币用 | 【史料】 |
| 俸禄 | 比四百石：**月谷四十斛** | 【史料】《后汉书·百官志》 |
| 物价 | 汉末战乱，粮价飞涨，一斛谷可达数百钱甚至更多 | 【推断】 |

> **写作可用**：魏讽月俸四十斛，养两三口人尚可，但要**请客、养门客、打点关系**，就很紧。这解释了他为什么"有身份但没钱"。

### 3.8 文书与信息传递

| 项 | 内容 | 标注 |
| --- | --- | --- |
| 载体 | **木牍、竹简**为主；**帛书**用于重要信件；纸已出现但昂贵 | 【史料】 |
| 封缄 | 木牍用**检**（盖板）加**封泥**，盖印 | 【史料】 |
| 传递 | 专人送信；官府有**邮驿** | 【史料】 |
| 书写 | 毛笔、墨、砚；竹简用刀削改 | 【史料】 |

> **写作可用**："名单"写在木牍上，一卷木牍大约能写几十个字到百余字。**"一卷没写完的名单"这个意象成立。**

## 四、制度：官制与俸禄

### 4.1 魏国官制（建安二十一年以后）

- 【史料】建安二十一年，曹操进爵**魏王**，以**钟繇为相国**
- 【史料】相国之下设**诸曹掾属**，西曹为其一
- 【史料】黄初元年，相国改称司徒

### 4.2 西曹掾的位置

| 项 | 内容 | 标注 |
| --- | --- | --- |
| 品秩 | **比四百石** | 【史料】 |
| 职掌 | **相国府内员吏的人事选授** | 【史料】 |
| 印绶 | 铜印黄绶 | 【史料】 |
| 实际权力 | 官不大，但**能决定谁做官**，所以人人结交 | 【推断】 |

> **这是全书最重要的制度设定**：魏讽的"倾动邺都"，一半靠嘴，一半靠**人事权**。

### 4.3 长乐卫尉

| 项 | 内容 | 标注 |
| --- | --- | --- |
| 职掌 | 掌**长乐宫**宫门守卫 | 【史料】 |
| 品秩 | 九卿之一，中二千石 | 【史料】 |
| 关键 | **手里有宫门钥匙** | 【推断】 |

> 陈祎的官比魏讽大得多。这也解释了为什么魏讽必须拉他入伙——没有他，进不了宫门。
