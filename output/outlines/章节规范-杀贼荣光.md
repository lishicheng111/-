# 章节规范：《三国：杀贼荣光》

- 日期：2026-11-09
- 版本：v0.1
- 状态：草稿
- 依赖：AGENTS.md 红线、[情绪流总览](../../wiki/craft/emotion/情绪流总览.md)、用户日产 6000 字约束
- 用途：章节怎么切、每章多少字、每章什么结构

## 一、字数

| 项 | 规范 | 理由 |
| --- | --- | --- |
| 单章 | **2800 ± 300** | 起点历史文主流区间；过 3000 拆章，低于 2000 并章 |
| 日更 | 6000 字 ≈ **2 章/日** | 用户产能红线 |
| 存稿 | 周存稿 ≥ 6 章 | 防断更；低于 6 章触发预警 |
| 黄金三章 | 每章 ≥ 3000，宁长勿短 | 三江/新书期首因效应 |

## 二、单章施工图（每章填一张）

```
【章号】第 X 章 【时间】八月廿X 申时 【地点】西曹官署
【主事件】(详写 60%)：本章只许一个
【副事件】(略写 20%)：1-2 个，出信息或出人
【本章收益】三选一：新信息 / 新问题 / 旧信息回收
【章末钩子】危机型 / 悬念型 / 反转型 三选一，写明下一章发生什么
【倒计时】距案发还有 N 天（第一卷每章必标）
```

## 三、章内节奏（2800 字怎么切）

| 段 | 字数 | 内容 |
| --- | --- | --- |
| 开头 | 300 | 回接上章钩子 + 抛本章悬念 |
| 上半 | 1000 | 主事件展开，演说/推演/交锋 |
| 中点 | 200 | 节拍器：一次落空、一次代价或一次反转 |
| 下半 | 1000 | 主事件收口，收益到账 |
| 结尾 | 300 | 章末钩子，具体到人/事 |

## 四、详略 3:1

详：对话交锋、演说全文、决策过程。
略：赶路、等待、日常事务（一句话带过 + 出一个细节）。
**等距时间线禁止**：连续两章不能是同样的"开会→散会→回家"结构。

## 五、钩子三型（轮换使用，禁连用同型）

| 型 | 定义 | 例 |
| --- | --- | --- |
| 危机型 | 立刻的威胁 | 驿使冲进院："全军没了！" |
| 悬念型 | 新变量入场 | "长乐卫尉陈祎，拜谒西曹。" |
| 反转型 | 旧认知被砸 | "他查到的名单上，第一个名字是自己。" |
