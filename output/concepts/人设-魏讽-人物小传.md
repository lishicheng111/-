## 〇、一句话

**一个寒门县吏的儿子，靠一张嘴爬进相国府，最后想用这张嘴烧掉整座邺城。**

## 一、身份卡（史料速查，写正文前必看）

| 项 | 内容 | 标注 |
| --- | --- | --- |
| 姓名 | 魏讽，**字子京** | 【史料】《世语》 |
| 籍贯 | 祖籍济阴，父辈迁居沛国 | 【构思】圆两说 |
| 年龄 | 建安二十四年约 35–40 岁 | 【构思】 |
| 官职 | 魏相国钟繇府**西曹掾** | 【史料】 |
| 品秩 | 秩比四百石，第七品 | 【史料】 |
| 职权 | **掌相国府员吏的人事选授** | 【史料】 |
| 家世 | 寒门，非士族 | 【构思】 |
| 外貌 | 中等身量，声音极好，一开口全场安静 | 【构思】 |

> **称呼规则**（写错立刻出戏）：
> - 同辈、朋友称"**子京**"
> - 下属、门生称"**魏掾**"或"**先生**"
> - 长辈、上官称"**子京**"
> - **不要写"魏讽大人"**——汉代不这么称呼

## 二、家境（全属构思，但每一条都有用途）

### 设定

| 项 | 设定 | 叙事用途 |
| --- | --- | --- |
| 阶层 | 寒门，父亲是县功曹（县衙小吏） | 解释他为什么必须靠"名"上位 |
| 田产 | 薄田三十亩，勉强度日 | 他有钱请客、没钱置产，只能靠嘴 |
| 藏书 | 父亲手抄的《春秋》《律令》各一卷 | 他的学问来源，也是他的软肋——只通实务，不通经学 |
| 社会位置 | 沛国是曹操老家，曹氏、夏侯氏遍地 | 他是"老乡"，却反老乡，反差最大 |

### 核心设计：他为什么必须靠嘴

魏讽不是士族。汉末没有科举，寒门子弟只有两条路：**军功**或**名声**。他不能打仗，只剩名声。

这就是他"倾动邺都"的真正动力——**他不是天生爱演讲，是不演讲就没有出路。**

> 这条设定让"演说家"人设有了苦味：每一次慷慨陈词，背后都是一个寒门子弟对命运的挣扎。

### 为什么兴汉（最重要的一条）

【构思】**他父亲一辈子按汉律办事。**

- 汉代吏员升迁靠"**功次**"——年头到了、考核过了，就能升
- 父亲做了二十年县功曹，攒了一身功次，等着升县丞
- 父亲死后，魏讽拿着功次文书去求迁转，被曹魏的新制挡回：**现在看军功、看门第，不看功次**
- 他那一刻明白：**汉制里，他父亲那样的人有位置；魏制里，没有**

所以他的"兴汉"不是抽象的忠君，是**"我这类人该有一个位置"**。

> 这个动机的好处：不中二、不空洞、不敏感。它甚至能让现代读者共情——**一个被制度挤出去的人，想换回旧制度。**

## 三、父母（全属构思）

### 父亲：魏崇，字不详

- 沛国县功曹，通《春秋》，能背汉律
- 建安初年死于疫病，年约四十五
- 为人谨小慎微，一生没出过沛国
- **临终遗言**："**士无族，唯有口。**"

> 这句话是魏讽一生的信条，也是他的墓志铭。成也口，败也口——正好对应三国杀技能"祸终"。

### 母亲：张氏

- 不识字，但能口诵《诗经》数篇（乡里口传）
- 织履补贴家用，供魏讽读书
- 反对魏讽结交权贵，说过："**你爹就是因为话多，才一辈子没升上去。**"
- 【可选】案发前一年病故——这样魏讽在被诛前，已经没有牵挂，也没有人能劝住他

> 母亲的死可以做成"他为什么敢赌命"的解释：**他不是不怕死，是没什么可失去的了。**

### 一个细节（强烈建议用）

魏讽发达后，把父亲那卷手抄《律令》带在身边，用锦囊装着。他从不给人看，但每晚睡前摸一下。

**案发前夜，他把锦囊烧了。** ——这是他决定"不回头"的仪式。

## 四、住处（基于邺城布局构思）

### 位置

邺城**北区、宫城以东、戚里外围**的一处**租赁小宅**。

- 【史料支撑】邺城宫城以东是官署区和贵族聚居的戚里
- 【构思】魏讽是四百石小官，住不起戚里，只能在戚里外围租宅
- 步行到相国府约一刻钟——他每天走着去上班

### 格局（这是重要的戏台）

```text
        巷口（常有求官者等候）
          │
    ┌─────┴─────┐
    │   前  院   │  ← 老槐一株，石案一张，可坐十余人
    │  （清谈）  │     这里是他的"演说场"
    ├───────────┤
    │   后  院   │  ← 母亲生前住处，现空置
    │  （独处）  │     他在这里写名单
    └───────────┘
```

| 空间 | 用途 | 可承载的戏 |
| --- | --- | --- |
| **巷口** | 求官者排队 | 开篇可写"门口等了七个人"，一句交代他的权势 |
| **前院老槐下** | 清谈、演说、结党 | 名场面"让邺城燃烧"可在此发生 |
| **后院** | 独处、写名单、烧锦囊 | 开篇 A"手里攥着一卷没写完的名单"就在此处 |
| **井** | 可藏可毁 | 案发前夜，名单投井或烧毁，二选一 |

> **空间即人设**：前院越热闹，后院越空。这个对比就是他的一生。

## 五、与史书人物的关系（逐人：史料 + 小说设计）

### 钟繇（恩主）

- 【史料】魏国相国，力荐魏讽为西曹掾；案发后坐免
- 【构思】**第一次见面**：钟繇问他"何以治邺"，魏讽不谈治国，只讲钟繇当年说服李傕、郭汜放天子东归的旧事，讲得钟繇眼眶发红。钟繇当场辟他为掾。
- 【构思】**魏讽的可怕**：他总能说出对方最想听的话。这不是谄媚，是他真的懂人。
- 【构思】**关系本质**：钟繇把他当"门客"，他把自己当"同道"。这个错位是悲剧起点。

> 一句可用的台词（钟繇被免官后）："**我荐你，是因为你说中了我；我害了你，也是因为你说中了我。**"

### 陈祎（同谋 → 告密者）

- 【史料】长乐卫尉，掌宫门；临期惧，向曹丕告密
- 【构思】**关系本质**：不是挚友，是**利益同盟**。魏讽需要他的门，他需要魏讽的名。
- 【构思】**他为什么告密**：不是单纯怕死。他到最后发现，魏讽要的不是"袭邺成功"，而是"死给天下看"——**魏讽想当烈士，陈祎不想陪葬。**
- 【构思】**最后一幕**：陈祎告密后，魏讽在狱中只说了一句："你终究是个守门的。"（呼应三国杀阵亡台词"陈祎，你竟然背叛了我"）

> 这个设计让陈祎不是"叛徒"标签，而是一个**做出了理性选择的人**。读者会恨他，但说不出他错在哪。

### 王粲二子（门生）

- 【史料】被魏讽"所引"，诛，王粲绝后；曹操叹"孤若在，不使仲宣无后"
- 【构思】两个年轻人，一个十九、一个十七，叫他"先生"，把他当精神领袖
- 【构思】**最重的债**：他们不是因为信仰而死，是因为**崇拜魏讽**而死
- 【构思】魏讽在狱中得知二人已死，第一次说不出话

> 这是全书的情感核心。魏讽可以接受自己死，不能接受**别人因为信他而死**。

### 刘伟（同党）

- 【史料】刘廙之弟，与魏讽交好，参与；曹操以"叔向不坐弟虎"特免刘廙
- 【构思】刘廙曾写信劝弟弟远离魏讽，刘伟把信拿给魏讽看
- 【构思】魏讽看完，笑着说："**你兄长是对的。**"然后继续讲他的计划
- 这一句"你兄长是对的"，能同时立住他的清醒与自负

### 刘晔、傅巽、郑袤、王昶（四个预言者）

- 【史料】四人都早说魏讽"必反""必以祸终"
- 【构思】**统一处理**：魏讽都曾试图结交他们，都被拒绝
- 【构思】最狠的一次：他去刘晔府上，门房说"主人不在"。他在门外站了半个时辰，然后对随从笑说："**他怕我。**"
- 【构思】这四个人的存在，构成"所有人都看出来了，只有他自己不承认"的宿命感

### 任览（好友，史料里的一个钩子）

- 【史料】《晋书·郑袤传》：郑袤对任览说"讽奸雄，必以祸终，子宜绝之"
- 【构思】任览是魏讽为数不多的真朋友。他听了郑袤的话，但没绝交
- 【构思】**他的选择是个悬念**：案发后，他到底是告发了魏讽，还是替他收尸？
- 建议：**让任览活下来，替他收尸。** 这样全书最后有一点点暖

## 六、语言习惯（写对话时对照）

### 三个特征

1. **短句多，反问多**——他不长篇大论，他一句一句逼你
2. **善用对方的话反击**——先复述你的观点，再拆掉它
3. **情绪最高时反而放低声音**——真正的煽动不是喊，是让人凑近听

### 口头禅（可用）

| 场合 | 台词 |
| --- | --- |
| 逼人表态 | "这话，你敢当众说吗？" |
| 拆人逻辑 | "你说得对。可你想过没有——" |
| 自我辩解 | "**事败才叫造反，功成即是勤王。**"【史料化用】 |
| 煽动 | "让邺城燃烧，让奸贼陨落。"【三国杀台词】 |
| 面对死亡 | "**我这一生，只输在话说得太早。**" |

### 禁忌

- 不要让他讲现代词汇（格局、底层逻辑、赋能）
- 不要让他连续说三段以上长台词——他是演说家，不是朗诵家
- 他的每段话都要有**听众反应**（点头、变色、后退），否则就是干说

## 七、人物弧光

| 阶段 | 信念 | 转折 |
| --- | --- | --- |
| **起点** | 口能改命 | 靠一张嘴从县吏之子做到相国掾 |
| **中点** | 口被人当刀 | 发现曹丕正等着他动手 |
| **终点** | 口还能说真话 | 明知必死，仍要在刑场上把话说完 |

> 弧光的核心不是"他变强了"，而是"**他明白了嘴的边界**"——嘴能煽动万人，却救不回两个叫他先生的孩子。

## 九、三个仍空缺、需要你拍板的点

1. **穿越者与原主的关系**：是"记忆融合"（两个人格打架），还是"完全取代"（原主死了）？前者更有戏，但更难写。
2. **婚配**：史书无载。写"未娶"最省事，也最孤独；写"有妻"能多一条情感线，但要处理"妻儿怎么办"的问题。
3. **子嗣**：建议写"无后"。王粲因二子被诛而绝后，魏讽若也无后，两个"绝后"形成互文。
