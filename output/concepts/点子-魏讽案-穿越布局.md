## 一句话核心

**穿越到魏讽案发前几天，用一场"演说"改写一场被史书一笔带过的政治清洗。**

## 一、素材：三国杀里的魏讽（人设原型）

| 项 | 内容 |
| --- | --- |
| 势力/体力 | 魏 / 3 勾玉 |
| 称号 | 趁浪逐波 |
| 扩展包 | SP·绕庭之鸦 |
| 技能 | 惑众、鸠合、祸终（觉醒后转为"崩坏"） |
| 网友评价 | "三国杀最激昂之人""三国演说家" |

### 台词（人设金矿）

- **"事败才叫造反，功成即是勤王。"** ← 全设定最强的一句，自带主题
- "让邺城燃烧，让奸贼陨落。"
- "杀贼之荣光，我魏讽岂能独享！"
- "一声魏王！没了五十万枯骨~"
- 技能台词："攻克邺城，里应外合。""外有强援，必能致胜。"
- 觉醒/败亡："祸从口出，终究取败。"
- 阵亡："陈祎，你竟然背叛了我。"

### 技能即人设

- **惑众**：靠"说"影响他人牌局 → 演说家、煽动者
- **鸠合**：拼点、里应外合 → 串联、结盟、策反
- **祸终**：越强越走向"崩坏" → 成也口舌，败也口舌

> 注意：三国杀形象是游戏二创，不是史实。但它给小说提供了一个**极鲜明的人设锚点**：一个靠嘴、靠激情、靠"正当性叙事"行动的人。

## 二、素材：史实与争议（信息差富矿）

### 史实骨架

- 魏讽，沛人（一说济阴），相国**钟繇**的西曹掾，官职不大
- "有惑众才，倾动邺都""有重名，自卿相以下皆倾心交之"
- 建安二十四年（219）九月，曹操在外（汉中/荆州方向），魏讽**潜结徒党**，联合长乐卫尉**陈祎**谋袭邺城
- 事未发，**陈祎惧，向曹丕告密**
- 曹丕大清洗，**连坐死者数千人**，钟繇坐免

### 争议（关键）

- 网友与部分研究者认为：魏讽案可能是**一场被放大的政治清洗**，真实目的是替曹丕代汉建魏扫清亲汉势力
- 佐证：案子牵连数千人，远超一个"西曹掾"能撬动的规模；《三国志》记载极少，疑点重重

### 三句史料判词（可作人物弧光）

- 傅巽："必反。"（看人极准）
- 郑袤："讽奸雄，必以祸终。"
- 王昶："以倾邪败没，荧惑当世。挟持奸慝，驱动后生。"

## 三、核心玩法：几天倒计时 + 布局

这个点子天生自带项目最爱的**倒计时结构**：

```text
穿越落地 → 距离"历史发案日"只剩 3–7 天
   ↓
信息收集（谁是陈祎？谁会告密？曹丕知道多少？）
   ↓
布局（演说串联 / 策反 / 自证清白 / 提前引爆）
   ↓
倒计时归零 → 案发 or 改命
```

**时间锁 + 空间锁双锁**：几天内、邺城内。跑不掉，只能布局。

## 四、两个主角方案（待选）

### 方案 A：穿越成魏讽（居中）

- 你知道史书上你失败了、死了、还连累数千人
- 你要在几天内：要么真的政变成功，要么自证清白活下来
- 爽点：用"演说"煽动邺城、策反关键人物、把必死局翻盘
- 风险：主角是"造反者"，立场敏感；且"成王败寇"容易写成中二

### 方案 B：穿越成陈祎（不居中，推荐）

> 承接上一个点子的偏好：主角不是线路居中的人。

- 你穿越成**历史上那个告密者**
- 你知道：只要你告密，数千人死；你不告密，可能案成、可能案败、你可能死
- 核心张力：**你是历史的扳道工**，一个无名小人物握着数千人的生死
- 爽点：不是打架，是**在几方势力间周旋、传递真假信息、操控局势**
- 主题：历史书上你是"叛徒"，但你可以选择做别的

**方案 B 的优势**：主角有天然的道德困境 + 信息优势 + 小人物改大历史的爽感，且避开了"造反者"的立场风险。

## 五、开篇点子（备选）

### 开篇 A：醒来即倒计时

> 我睁开眼，身上穿着一件不属于我的官服。
>
> 案头压着一张字条，墨迹未干："三日后，子时，邺城南门。"
>
> 落款两个字：魏讽。
>
> 我翻了翻原主的记忆，终于想起我是谁——我是陈祎。三天后，我会去告密，然后几千人因我而死。

- 钩子：读者立刻知道"我知道历史，且我是关键变量"
- 爽点：信息差 + 倒计时
- 主题：小人物的选择

### 开篇 B：演说开场

> "事败才叫造反，功成即是勤王。"
>
> 台下数百人鸦雀无声。
>
> 我站在人群里，看着台上那个叫魏讽的人，忽然想起：这句话，三天后会要了几千条命。
>
> 而决定它成真的，是我。

- 钩子：先给"演说家"名场面，再反转出"我是告密者"
- 优势：第一屏就有强画面 + 强台词

### 开篇 C：反着来

> 史书上说，我告了密。
>
> 那这一次，我偏不告。
>
> 我倒要看看，不告密的陈祎，能活几天。

- 钩子：直接对抗历史，读者好奇"改了会怎样"
- 风险：少了悬念（读者知道他要干什么），需要靠"过程多难"撑

## 六、为什么这个点子适配项目方法论

| 项目方法论 | 本点子的对应 |
| --- | --- |
| 倒计时开篇法 | 案发前 3–7 天，天然倒计时 |
| 时间锁与空间锁 | 几天内、邺城内，跑不掉 |
| 信息差 | 史书记载极少 + 穿越者知道结局 |
| 反向信息差 | 读者知道历史，主角要改历史 |
| 小人物改大历史 | 陈祎一个卫尉，握着数千人生死 |
| 演说家人设 | 稀缺主角类型，不靠武力靠嘴 |
| "跟爆款找新切口" | 三国是红海，但魏讽案是冷门切口 |

## 七、风险

| 风险 | 说明 | 初步对策 |
| --- | --- | --- |
| 历史考据争议 | 魏讽案史料少，易被考据党挑错 | 明确"架空/演义"定位，开篇标注 |
| 立场敏感 | "造反"在历史文里要处理得当 | 选方案 B（陈祎视角），避开造反立场 |
| 三国红海 | 三国穿越极多，容易淹没 | 主打"冷门案件 + 演说家 + 几天倒计时"差异化 |
| 智斗门槛 | 布局流需要逻辑严密，写崩就难看 | 用"倒计时 + 每章一个棋子"控制复杂度 |
| 结局两难 | 改历史 or 不改，都不好写 | 提前定结局：历史大势不改，但小人物的选择被记住 |
