## 〇、先定版本：这是"三国志"素材，不是"三国演义"

**《三国演义》里魏讽几乎没有任何戏份。** 演义的重心在关羽北伐、水淹七军、败走麦城，魏讽案连一笔带过都没有。

这意味着：

| | 三国演义 | 三国志 |
| --- | --- | --- |
| 魏讽戏份 | 几乎为零 | 散见 5–6 篇传记 |
| 读者认知 | 低 | 低 |
| 创作自由 | 高 | 高 |
| 需要标注 | "架空/演义" | "依据《三国志》" |

**结论**：本书应定位为**《三国志》向的历史文**，而不是演义同人。好处是没有演义既定情节的束缚；坏处是读者认知度完全依赖三国杀。

## 一、魏讽本人身份卡（目前能查到的全部）

| 项 | 内容 | 出处 |
| --- | --- | --- |
| **字** | **子京** | 《世语》："讽字子京，沛人，有惑众才" |
| 籍贯 | **沛人**（《世语》）／**济阴**（王昶《家诫》），两说并存 | 《世语》《王昶传》 |
| 官职 | 魏相国**钟繇**府**西曹掾** | 《世语》《册府元龟》 |
| 品秩 | **秩比四百石，第七品** | 《三国会要·职官》 |
| 职权 | **掌相国府内员吏的人事选授** | 官职考 |
| 名声 | "有惑众才，倾动邺都""有重名，自卿相以下皆倾心交之" | 《世语》《傅子》 |
| 结局 | 诛，**坐死者数十人** | 《世语》 |

> **关键发现：西曹掾掌人事任免。** 这解释了他为什么能"倾动邺都"——不只是因为他会演讲，更因为他**能决定谁做官**。名声 + 人事权，才是他真正的权力来源。这也解释了为什么"自卿相以下皆倾心交之"：他们交的不是魏讽，是位置。

> **籍贯两说的圆法**：小说可设定"祖籍济阴，父辈迁居沛国"，两说都成立，还能给他一个"外来户"的身份焦虑。

### 邺城空间（写作用）

| 区域 | 内容 |
| --- | --- |
| 整体 | 东西约 2500 米、南北约 1700 米，横长方形；一条东西向大道分南北两区 |
| 北区中部 | 宫城，正殿**文昌殿**，南北中轴线（端门—止车门—中阳门） |
| 宫城以东 | 贵族聚居的**戚里** + **官署区** |
| 宫城以西 | **铜爵园**，内置武库、马厩、仓库 |
| 西北 | 三台：**铜雀台、金凤台、冰井台**（建安十五年筑） |
| 南区 | 居民**里坊** |

> **写作可用**：相国府在北区宫城以东的官署区，魏讽每日出入此处；三台是邺城地标，任何"登高望远"的戏都可放铜雀台；武库在宫城西侧，是"袭邺"必须控制的点。

## 三、必须更正的三个史实错误

### 错误 1：死者人数不是"数千人"

- 点子卡初稿写"连坐死者数千人"，**不准确**
- 《世语》原文：**"诛讽，坐死者数十人"**
- "数千人"的说法流传于网络文章，**未见可靠史料支撑**
- **处理建议**：小说里可以写"数十人"，但用"牵连者众、人人自危"来渲染气氛；如果要写大规模清洗，需明确是"演义化处理"

### 错误 2：事发地是"邺城"，不是"许都"

- 曹操封魏王后，**魏国都城在邺城**
- 曹丕留守邺城，所以陈祎才向曹丕告密
- 许都是汉献帝所在，不是魏国政治中心
- **写错会直接被考据党抓住**

### 错误 3：陈祎的职位是"长乐卫尉"

- 长乐卫尉 = 掌**长乐宫**宫门守卫的武官
- 这个职位意味着他**能开宫门**——这是"内应"的关键
- 不是随便一个文官，是**手里有门钥匙的人**
- **创作价值**：陈祎的叛变之所以致命，是因为他掌握物理上的入口

## 四、魏讽的动机：三种可能（供选择）

| 说法 | 依据 | 小说可用性 |
| --- | --- | --- |
| **亲汉反曹** | "心存汉室"说（百科） | 立场敏感，需转成"勤王"叙事 |
| **呼应关羽** | 时间点 + 荆州系人脉（王粲、刘廙、宋忠均与荆州有关） | ★★★ 最好用，有具体外应 |
| **被利用的棋子** | 曹丕借案清洗亲汉势力，为代汉铺路 | ★★★ 最有反转空间，可做暗线 |

> **最强组合**：魏讽自以为在"响应关羽、匡扶汉室"，实际上被曹丕**顺水推舟**做成了清洗借口。主角穿越后逐渐发现：自己不是在造反，是在被人当刀使。

## 五、可直接用 / 不能改 清单

### 可直接用（史实支撑）

- 魏讽是钟繇的西曹掾，钟繇力荐
- "有惑众才，倾动邺都""自卿相以下皆倾心交之"
- 陈祎是长乐卫尉，临期告密
- 王粲二子被诛，曹操叹"孤若在，不使仲宣无后"
- 刘廙因弟刘伟获罪，曹操以"叔向不坐弟虎"特原不问
- 刘晔、傅巽、郑袤、王昶四人都预言魏讽必败
- 时间：建安二十四年九月，关羽威震华夏同期

### 不能改（改了会被考据党骂）

- 曹操当时不在邺城
- 曹丕是留守方和主审
- 关羽此时在荆州方向，不可能亲自到邺城
- 钟繇事后确实被免官

### 可自由发挥（史书空白）

- 魏讽的具体计划、同党名单细节
- 陈祎告密的具体过程
- 魏讽与王粲二子、刘伟的交往细节
- 曹丕的真实意图
- 魏讽的内心世界（史书只有"倾邪""奸雄"的判词）

## 六、素材缺口（下次要补）

1. 《三国志·钟繇传》原文——确认魏讽案后钟繇的具体处置
2. 《世语》全文——确认"坐死者数十人"的上下文
3. 张泉、宋忠之子、文钦是否真的牵连（目前只有二手来源）
4. 邺城的地理布局（宫门、长乐宫位置）——写"内应"需要
5. 建安二十四年邺城的守军配置

- 《三国志·魏书·王昶传》："近济阴魏讽、山阳曹伟皆以倾邪败没，荧惑当世。"
